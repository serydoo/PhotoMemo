## 本轮事实源

- 将 iOS 根视图中相互关联但职责不同的状态整理为编辑交互、输出草稿、配置投影、生命周期和根视图呈现等明确容器，继续以 `ConfigurationSession` 作为实时配置真相。
- 保留 `Library -> Interactive Memory Card -> Object Inspector` 的 Configuration Center 结构，未恢复旧的 Workspace、Dashboard 或 Import Flow。
- 为相册选项的异步加载保留记忆对象与配置身份校验，避免切换后过期结果写回当前页面。
- 为拆分后的状态容器增加契约回归测试，覆盖保存/恢复边界、输出草稿、根视图呈现和对象/配置身份连续性。
- PhotoKit 静态图与 Live Photo 保存现在共享两阶段 receipt/intent 生命周期；队列恢复会在确认可见资产后升级本地提交状态，避免在确认不足时投影为完成。
- Apple ProRAW 的类型声明改为 imported UTI，并补充输入策略、receipt/queue、PhotoKit 保存和 Device QA contract 覆盖。
- `MemoMarkDeviceQA` target、共享 scheme、QA manifest、UI harness 和本地验证脚本已纳入工程，但它们仍然是非破坏性验证基础设施，不等于 QA-01 至 QA-08 或生产认证全部通过。
- 本轮没有改变 Renderer/Layout Engine 的所有权，也没有修改原始照片保护原则；PhotoKit、Share Extension 和 Live Photo 的边界变化均属于可靠性工程修复。

## 应用内“更新日志”

这次更新主要完善了配置中心在切换与恢复时的状态连续性。

- 切换记忆对象、配置和编辑页面时，当前卡片内容会继续跟随正在处理的记忆。
- 卡片编辑与输出设置的状态边界更清楚，减少旧页面状态覆盖当前编辑的机会。
- 重新进入配置中心或切换记忆对象后，预览、对象信息和配置选择会保持在同一上下文。
- 相册选项等异步内容只会应用到仍然对应的记忆对象和配置，避免过期结果混入当前页面。
- 照片仍在设备本地处理，原图保持不变；完成后生成新的记忆照片。

## In-app “What’s New”

This update keeps Configuration Center state consistent when you switch and return.

- When you switch subjects, configurations, or editor pages, the current card content continues to follow the memory you are working on.
- Card editing and output settings now have clearer state boundaries, reducing the chance that an older page overwrites the current edit.
- After reopening Configuration Center or switching subjects, the preview, subject details, and configuration choice stay in the same context.
- Asynchronous album options are applied only when they still belong to the current subject and configuration, so stale results do not enter the page.
- Photos remain processed on device and originals stay unchanged; MemoMark creates a new memory photo when finished.
