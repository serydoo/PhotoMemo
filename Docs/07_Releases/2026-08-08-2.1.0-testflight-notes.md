# MemoMark 2.1.0 (72) TestFlight 测试说明

本次测试版来自近期部分用户反馈促成的一轮界面、卡片编辑与分享体验整理。

请重点验证：

- 四个卡片区域是否与 Renderer 预览中的左上、左下、右上、右下对应；
- 卡片右下内容是否写入照片说明，并可在 Apple Photos 中查找；
- 收起键盘是否只收起键盘，点击“完成”后四区是否统一保存；
- Share 页面是否清楚展示照片、配置、相册和处理状态；
- 原图是否保持不变，新结果是否回到 Apple Photos；
- 基础白边框和“更多样式将在后续版本陆续开放”的提示是否清楚。

请通过 TestFlight 的“发送 Beta 版反馈”提交问题，并附上页面、操作步骤、设备型号、iOS 版本和必要截图。无需提交私人原始照片、人物信息、地点或完整资产标识。

本测试用于收集真实设备证据，不代表所有生产可靠性验证已经完成。
