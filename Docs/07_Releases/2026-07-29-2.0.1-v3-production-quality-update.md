# MemoMark 2.0.1 版本更新说明

日期：2026 年 7 月 29 日
版本：`2.0.1 (48)`
整理范围：2026 年 7 月 27 日至 7 月 29 日

## 版本定位

`2.0.1` 是 MemoMark V3“生产质量与交付”阶段的一次稳定性与体验更新。它延续
本地优先的 Memory Presentation Engine，不上传照片，不修改 Apple Photos 中的
原始照片，只生成新的记忆结果。

这次更新没有重新设计冻结的 Configuration Center、Memory Engine、Presentation
Engine、Layout Engine、Renderer、Export 或 Apple Photos 工作流，而是把已经存在的
产品边界做得更可靠、更容易理解。

## 主要更新

### 1. Apple Photos 分享与记录更稳定

- 加强 Share Extension 到后台处理的持久交接，避免请求在保存不确定时提前消失。
- 后台任务区分等待、可恢复中断、权限需要、永久失败和已完成状态。
- 系统后台时间结束时保留可恢复状态，不把取消误报为普通失败或完成。
- 收紧队列启动、恢复、重试和通知清理的边界，降低重复保存和任务丢失风险。
- 延续大图库保存路径的轻量化检查，避免主线程遍历完整照片库导致任务停在 99%。

### 2. 配置中心与记忆对象更可靠

- 加固配置保存、恢复、备份、删除和冲突处理，保留损坏数据的诊断边界。
- 切换记忆对象时同步正确的活动配置、时间锚点和编辑状态。
- 配置重命名后继续编辑和保存时保留新名称。
- 配置预览继续使用真实 Memory Card，未引入脱离渲染链的抽象预览。
- 新增“高级模块”入口，把地理显示等扩展选项从主要卡片内容中整理出来。

### 3. iPhone 界面和设置中心完成一轮收口

- 拆分 iOS 根视图中的导航、配置页、区域编辑、演示层和生命周期观察边界，保留
  `ConfigurationSession` 作为编辑真相。
- 优化首页、配置、保存、处理、输出、记忆对象和时间锚点的层级、行布局和主要操作。
- 为紧凑设备、窄屏、较大文字和辅助功能字号补齐垂直布局与菜单回退。
- 设置页整理为“开始使用 -> 照片处理 -> 数据安全 -> 反馈 -> 社区 -> 界面语言 -> 关于”。
- “关于 -> 更新日志”现在直接在应用内打开本版本说明，不再跳转到 GitHub Releases。

### 4. 记忆表达与产品语言更自然

- 建立并应用 Narrative Product Language，围绕人、重要时刻和回忆表达产品内容。
- 设置内的记忆表达说明支持时间锚点、表达方式和 Before / On Anchor / After 示例。
- 中英文界面资源同步更新，保留智能模块输出时间结果、用户决定最终句子的规则。
- 对权限、隐私、错误、恢复、购买和删除等需要准确说明的状态继续使用直接表达。

## 保持不变

- 照片只在设备本地处理，不上传。
- 原始照片保持不变，MemoMark 生成新的输出照片。
- 日常流程仍然是：Apple Photos -> Share -> MemoMark -> Processing -> Notification -> Apple Photos。
- BrandMark 研究、私有照片/数据集、签名 IPA、归档和设备私有证据不属于本次同步范围。

## 验证与发布边界

- 本轮新增和调整了设置、背景处理、响应式布局、叙事语言、配置生命周期和媒体输出契约测试；
  时间显示预览也修正为日期与时间 token 分开格式化，避免默认卡片重复显示完整日期。
- 中英文 `Localizable.strings` 通过 `plutil -lint`，版本号和构建号在 Xcode 工程配置中统一为
  `MARKETING_VERSION = 2.0.1`、`CURRENT_PROJECT_VERSION = 48`。
- 完整 macOS `PhotoMemoTests` 回归通过：`1,207` 项通过、`1` 项跳过、`0` 项失败；
  macOS、通用 iOS 和 Share Extension Debug 构建均通过。
- 物理设备已有签名安装和启动证据；完整 Apple Photos 分享、后台系统调度、VoiceOver、Dynamic Type 和最终视觉验收仍需在发布候选包上单独确认。
