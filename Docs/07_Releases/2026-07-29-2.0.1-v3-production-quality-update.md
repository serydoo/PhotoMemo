# MemoMark 2.0.1 版本更新说明

日期：2026 年 7 月 30 日
版本：`2.0.1 (48)`
整理范围：2026 年 7 月 27 日至 7 月 30 日

## 版本定位

`2.0.1` 是 MemoMark V3“生产质量与交付”阶段的一次稳定性、输出一致性与
使用体验更新。它延续本地优先的 Memory Presentation Engine：照片只在设备上
处理，不上传，也不修改 Apple Photos 中的原始照片，只生成新的记忆结果。

这次更新没有重新设计已经冻结的 Configuration Center、Memory Engine、
Presentation Engine、Layout Engine、Renderer、Export 或 Apple Photos 工作流。
工作的重点是让既有产品边界更可靠，让预览、保存和最终结果保持一致，并让不同
尺寸 iPhone 上的主要操作更清楚。

`2.0.1` 也标志着 V3 版本完成收尾。V4 已进入 Expression Style System 的研究与
产品定义，并将作为最后一轮持续打磨阶段，继续完善表达方式、主界面、既有功能、
操作逻辑和设备适配，不进行大规模核心流程或架构重构。V4 完成后，如果没有发现
影响正常使用的重大问题，MemoMark 将不再安排常规版本更新，进入稳定使用与必要
维护阶段。

## 主要更新

### 1. Apple Photos 分享、后台处理与交接界面更稳定

- 加强 Share Extension 到后台队列的持久交接；只有请求可靠保存或明确结束后，
  分享入口才会完成交接，降低任务提前消失的风险。
- 后台任务继续区分等待、可恢复中断、权限需要、永久失败和已完成状态；系统后台
  时间结束时保留可恢复状态，不把取消误报为普通失败或完成。
- 收紧队列启动、恢复、重试、通知附件和来源文件清理边界，继续降低重复保存、
  请求丢失和恢复状态被覆盖的风险。
- 保留大图库保存路径的轻量化检查，避免主线程遍历完整照片库导致任务停留在
  `99%`。
- Share 半屏交接界面保留原有功能与自动关闭流程，同时将处理说明改为四个原生行，
  补齐 44pt 主要操作触达区域、VoiceOver 标题语义和中英文资源，并移除重复的照片
  数量说明。

### 2. 配置保存、时间显示与最终结果保持一致

- 加固配置保存、恢复、备份、删除和冲突处理，保留损坏数据的诊断与恢复边界。
- 切换记忆对象时同步正确的活动配置、时间锚点和编辑状态；配置重命名后继续编辑
  和保存时保留新名称。
- 修复时间显示设置只在预览生效、最终结果回到默认格式的问题。保存的时间显示配置
  现在会进入生产快照和最终渲染上下文。
- 选择“日常记录”后，最终日期会与预览一致地保留星期，例如
  `2026年7月29日 星期三`；日期与时间继续分别格式化，避免默认卡片重复显示完整日期。
- 配置预览继续使用真实 Memory Card，并与最终输出共享同一时间格式化路径，没有
  引入脱离生产渲染链的抽象预览。

### 3. 高级模块与小屏配置体验更从容

- “高级模块”继续集中地理显示和时间显示，不扩展新的功能表面。
- 高级模块弹窗使用紧凑的 `390pt` 默认高度，保留向大尺寸展开；移除重复标题，并将
  地理显示、时间显示整理为两个原生列表行。
- 两个高级模块获得更充足的垂直留白和清晰的内部节奏，同时保留原生菜单、动态字体
  和辅助功能行为。
- `记忆表达` 在较小的 iPhone 正常文字尺寸下尽量保持标题与选择项同一行；空间确实
  不足或使用辅助功能字号时，仍会自动回退为垂直布局。
- 记忆表达选择胶囊按内容宽度呈现，不再在小屏回退后占满整行；其他配置项的宽度
  规则保持不变。

### 4. iPhone 界面与设置中心完成一轮收口

- 拆分 iOS 根视图中的导航、配置页、区域编辑、演示层和生命周期观察边界，继续由
  `ConfigurationSession` 持有编辑真相。
- 优化首页、配置、保存、处理、输出、记忆对象和时间锚点的层级、行布局和主要操作。
- 为紧凑设备、窄屏、较大文字和辅助功能字号补齐垂直布局与原生菜单回退，不使用
  机型分支压缩界面。
- 设置页整理为“开始使用 -> 照片处理 -> 数据安全 -> 反馈 -> 社区 -> 界面语言 ->
  关于”。
- “关于 -> 更新日志”直接在应用内显示本版本内容，不再跳转到 GitHub Releases。

### 5. 记忆表达与产品语言更自然

- 建立并应用 Narrative Product Language，让界面围绕人、重要时刻和回忆表达，而
  不是围绕实现术语组织内容。
- 设置内的记忆表达说明支持时间锚点、表达方式和 Before / On Anchor / After 示例。
- 中英文界面资源同步更新；智能模块仍只提供时间结果，最终句子继续由用户组合和决定。
- 权限、隐私、错误、恢复、购买和删除等需要准确理解后果的状态继续使用直接表达。

## 后续版本节奏

- `2.0.1` 是 V3“生产质量与交付”阶段的收尾版本。
- V4 已从 Expression Style System 的研究与产品定义开始，并继续打磨主界面、既有
  功能、操作逻辑、视觉节奏与设备适配；它不重新打开已经冻结的产品架构，也不进行
  大规模核心流程重构。
- V4 完成且没有影响正常使用的重大问题后，MemoMark 将停止常规版本更新，只保留
  对必要兼容性、系统变化和重大问题的维护。

## 保持不变

- 照片只在设备本地处理，不上传。
- Apple Photos 中的原始照片保持不变，MemoMark 生成新的输出照片。
- Live Photo 的既有处理与输出策略没有在本轮降级或重构。
- 日常流程仍然是：Apple Photos -> Share -> MemoMark -> Processing -> Notification ->
  Apple Photos。
- Configuration Center、Memory Engine、Presentation Engine、Layout Engine、Renderer
  和 Export 的既有职责边界保持不变。

## 验证与发布边界

- 新增和调整了设置、背景处理、响应式布局、叙事语言、配置生命周期、Share UI、
  时间显示快照和最终输出契约测试。
- 完整 macOS `PhotoMemoTests` 回归通过：`1,214` 项通过、`1` 项跳过、`0` 项失败。
- macOS 测试目标、通用 iOS Debug 构建和签名 iOS Debug 构建通过；主应用、Share
  Extension 和 Widget Extension 的嵌入签名通过严格校验。
- 中英文 `Localizable.strings` 通过 `plutil -lint`，版本号和构建号保持统一：
  `MARKETING_VERSION = 2.0.1`、`CURRENT_PROJECT_VERSION = 48`。
- 签名包已原位安装到一台 iPhone 17 Pro Max 和两台 iPhone 15 Pro，设备均确认安装为
  `2.0.1 (48)`，没有卸载应用或清除现有容器数据。
- 以上是构建、安装和自动化回归证据。完整 Apple Photos 分享、系统后台调度、
  VoiceOver、Dynamic Type、Live Photo 与最终视觉验收仍需在发布候选包上单独确认。
