# MemoMark 2.3.4（115）同步清单

状态：`Version Locked; Release Evidence Open`

## 1. 版本事实与决策门

- Product Loop 为主：产品负责人提供的两张 iPhone 截图证明卡片内容浮层遮挡预览，当前同屏检查器已实现且获得正面视觉反馈。
- 起点：`2a9dfef1`，即 `2.3.3 (111)` 发布提交；后续已提交的首页引导、预设行和预览方向改进，加上当前本地已实现的 UI/预览/FilmMark 溢出修复，合为本轮边界。
- Marketing version：`2.3.4`；build：`115`。Xcode Cloud 已显示 112 成功、113/114 在 App Store Connect 准备阶段失败；本轮不复用构建号。
- 所有权：Configuration Center 的临时编辑与预览保持各自状态源；Layout Engine 决定 Classic White 与 FilmMark 几何；生产健康检查在渲染前反馈溢出；Renderer、PhotoKit、Export 和持久化架构保持既有边界。
- Apple 原生能力：SwiftUI 同页检查器、UIKit/TextKit 编辑、系统键盘、VoiceOver、Dynamic Type；不引入自定义键盘或第二套预览渲染真相。
- 出口合规事实：当前源码中 `CryptoKit` 仅用于 Apple 系统提供的 SHA-256 摘要；未找到第三方加密依赖或自实现加密。按 Apple 关于仅使用系统加密且无需文档的说明，iOS 主 App `Info.plist` 标记 `ITSAppUsesNonExemptEncryption = NO`。115 处理后仍需核对 App Store Connect 的实际合规状态，不从 plist 字段推断已批准。
- 风险：主编辑流程与可访问性为 P1；四语文案、视觉一致性与版本维护为 P2。主要失效模式是键盘遮挡、编辑草稿与预览失联、长文字输出失败、Xcode Cloud 分发准备失败、出口合规未处理。
- 有界验证：版本契约、四语资源、聚焦与完整测试、iPhoneOS 构建、真机覆盖安装与启动、Xcode Cloud 115 构建、TestFlight 群组状态分别记录。
- 外部授权：用户本轮明确要求同步 GitHub 并在 TestFlight 发布；不包含正式 App Store 版本提交。
