# MemoMark 2.3.0（103）TestFlight 测试说明

## 测试重点

1. 使用新测试账户确认 MemoMark+ 订阅购买、待处理、恢复和有效期投影。
2. 使用历史永久权益账户确认重装、恢复、跨设备恢复以及全部第一方表达方式仍可用。
3. 使用已兑换历史激活权益的账户确认其能力与历史购买用户一致。
4. 在订阅有效期结束或撤销后，确认已有记忆仍可查看、导出和保留；新的付费表达或超出免费范围的操作才出现提示。
5. 从 Apple Photos 分享多张照片，验证 Share → Processing → Notification → Apple Photos 的完整链路，以及照片原始资源没有被修改。
6. 覆盖本地化、Dynamic Type、VoiceOver、家庭共享和订阅管理入口。

## 反馈信息

反馈请附：设备型号、系统版本、MemoMark 版本与构建号、权益类型（免费 / 历史永久 / 订阅 / TestFlight 临时体验）、触发路径、是否可恢复，以及是否涉及 Apple Photos 写入。

## 隐私提醒

测试照片保持在设备本地。请勿在反馈截图、录屏或日志中包含不必要的私人照片、姓名、地址或 Apple 账户信息。

## 状态边界

TestFlight Sandbox 中的购买不代表 App Store 正式版可用，也不代表外部测试审核已经通过。正式分发状态以 App Store Connect 页面为准。
