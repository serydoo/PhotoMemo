# MemoMark 2.2.2 (91) App Store「此版本的新内容」

> 本文件是待提交文案，不代表已上传或提交 App Store。提交前请以最终验证过的二进制和 App Store Connect 实际状态为准。

## 简体中文

```text
这次更新继续整理配置中心和卡片内容编辑体验：

• 文字、模块和光标在输入框内使用统一的稳定排版，插入、删除或重新排列模块时不再上下跳动。
• 空白、纯文字、中文标点和文字与模块混排都保持一致的输入高度与光标位置。
• 为后续卡片样式和编辑器保留统一的输入规范，减少不同页面之间的视觉差异。
• 延续本地处理、原始照片保护和 Apple Photos 保存回读的可靠性修复。
```

## U.S. English

```text
This update continues to refine Configuration Center and Card Content editing:

• Text, modules, and the caret now share stable input geometry, so inserting, deleting, or reordering modules does not make the line jump vertically.
• Empty fields, plain text, punctuation, and mixed text-and-module content keep the same input height and caret position.
• A shared input standard now guides future card styles and editors for consistent behavior.
• Local processing, original-photo protection, and Apple Photos save/readback reliability remain unchanged.
```
