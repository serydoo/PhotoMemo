# MemoMark 2.2.2 (95) App Store「此版本的新内容」

> 本次正式版说明包含上一轮 TestFlight 已交付的用户功能与修复。以下文案只描述用户可感知的变化，不包含测试术语、内部工程名称或未完成的认证承诺。

## 简体中文

```text
这次更新让配置中心、照片分享、卡片编辑和本地恢复更加连贯：

• 将照片说明和保存位置放回记忆卡配置路径，收起与展开选择也会被记住。
• 修复部分从 Apple Photos 分享后无法继续处理的问题，让照片接收、处理和恢复状态更清楚。
• 完整 Live Photo 在确认配对后以新的 Live Photo 保存回 Apple Photos。
• 生日、纪念日和倒计时继续保留各自的日常含义，照片中的时间表达更自然。
• 极简卡片现在会准确保留你在内容编辑区域组合的文字，并同步写入照片说明。
• 切换不同卡片样式时，各自的内容会独立保存，不再互相覆盖。
• 内容编辑器的标题与输入框改为更紧凑的同行布局，空白、纯文字、中文标点和文字与模块混排时，文字与光标保持稳定居中。
• 在模块前、模块后、模块夹中插入、删除或重新排列模块时，文字不会上下跳动。
• 修复自定义文字与多个模块混排时退格位置不准确、可能误删末尾模块的问题。
• 统一内容编辑中的模块胶囊样式；模块暂时无法识别时仍保留清晰的可读内容，不会变成空白。
• 复制和粘贴内容时保留文字与模块的组合关系，模块编辑也支持更完整的撤销恢复。
• 改进中断后的保存、恢复和长文字布局体验。
• 提升照片资源读取在不同系统和构建环境下的兼容性与稳定性。

照片仍只在设备本地处理，原图保持不变；完成后会把新的记忆照片保存回 Apple Photos。
```

## U.S. English

```text
This update makes Configuration Center, photo sharing, card editing, and local recovery easier to follow:

• Keep Photo Description and save destination with Memory Card settings, with remembered disclosure choices.
• Fix an issue that could stop some photos shared from Apple Photos before processing began, and clarify received, processing, and recovery states.
• Return a complete Live Photo to Photos as a new Live Photo only after its pairing is verified.
• Keep birthdays, anniversaries, and countdowns distinct so time-based expressions remain natural.
• Minimal now keeps your composed card content accurate in the image and its photo description.
• Card styles save their content independently, so switching styles no longer overwrites either one.
• Make Card Content Editor rows more compact with aligned titles and stable centering for empty fields, plain text, punctuation, and mixed text-and-module content.
• Keep text from jumping vertically when modules are inserted, deleted, or reordered before, after, or between text.
• Fix backspace behavior in mixed custom-text and module content so deletion stays next to the caret.
• Unify module capsules in Card Content Editor and keep an understandable fallback when a module cannot be resolved.
• Preserve text-and-module composition when copying and pasting, with more complete undo support for module edits.
• Improve recovery after interruptions and long-text layout behavior.
• Improve photo-resource lookup compatibility and stability across system and build environments.

Photos are still processed on device, originals remain unchanged, and completed memory photos are saved back to Apple Photos.
```
