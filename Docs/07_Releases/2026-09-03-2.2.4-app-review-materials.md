## App Review Notes（English）

```text
Hello App Review Team,

Thank you for reviewing MemoMark 2.2.4 (build 101).

MemoMark is a local-first memory presentation app built around Apple Photos. It does not require an account, login, or demo credentials. The core photo workflow does not require server communication. Photos selected by the user are processed on the device, the original asset is not modified, and MemoMark saves a new memory photo back to Apple Photos.

Core review path:
1. Open Apple Photos and select a JPEG or HEIC photo. A complete Live Photo may also be used to review the paired-media route.
2. Use the system Share sheet to share the photo to MemoMark.
3. If prompted, grant the Photos permissions needed to receive the shared photo and save the new result.
4. On first launch, follow the in-app setup to create a Memory Subject, choose a time anchor, and save the configuration.
5. Open Card Content Editor and review a plain-text line and a mixed text-and-module line. The editor keeps the text, module, and native caret aligned.
6. Optionally edit a Memory Subject avatar. Cancel once, then complete a crop and confirm that the selected subject keeps its updated appearance.
7. Return to MemoMark and open Progress if needed. Confirm that the photo is received, processed locally, and completed.
8. Open Apple Photos and confirm that a new memory photo is present. The original asset remains unchanged.

The optional MemoMark+ purchase is a non-consumable product. No purchase is required to review the core local photo workflow. If the purchase path is reviewed, it is available from Settings → MemoMark+ and uses StoreKit 2 product ID com.serydoo.PhotoMemo.iOS.memomarkplus.lifetime. Restore Purchases is available on the same page.

MemoMark does not upload photos, does not include user accounts, third-party advertising, or tracking. Shared settings and processing state remain in the app container or App Group on the device.
```

## 权限、隐私与购买边界

- Photos 权限只用于接收用户主动分享的照片和保存新的处理结果；原始资产
  不被修改。
- 没有账号注册、登录或测试账号；核心照片流程不依赖远程服务。
- 不上传照片、不使用第三方广告或跟踪；配置和处理状态仅保留在设备 App
  容器或 App Group。
- `MemoMark+` 为可选 Non-Consumable 商品；价格、生产交易、App Privacy、
  Export Compliance 和 Paid Apps Agreement 均应以最终二进制与 App Store
  Connect 为准。
