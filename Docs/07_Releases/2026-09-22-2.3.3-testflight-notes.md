# MemoMark 2.3.3（111）TestFlight 测试说明

状态：`Draft`；本轮只准备测试材料，尚未上传 TestFlight。

## 测试目标

验证从 2.3.0（105）以来持续完善的三种展示框架、FilmMark 自定义空间、Configuration Center、记忆对象与时间锚点、本地照片处理和四语界面，并确认 `2.3.3 (111)` 覆盖安装不会清除现有配置和照片数据。

## 建议测试路径

1. 在 iPhone 17 Pro Max 上覆盖安装 `2.3.3 (111)`，确认既有 App 容器、配置对象、Preset 和本地数据仍然存在；记录安装后的版本与构建号。
2. 打开设置中的“更新日志”，确认当前版本显示为 `2.3.3 (111)`，并确认三种展示方式、FilmMark 自定义空间和记忆对象整理的重点清楚可见；中文、English、日本語和한국어内容均完整、可滚动且没有内部工程术语。
3. 在 Configuration Center 中分别选择 Classic White、Minimal 和 FilmMark；检查选择状态、真实 Memory Card 预览、保存、重新打开和处理入口是否保持同一表达方式。
4. 新建或复制一个 Preset，选择 Minimal 后保存并处理一张静态照片；确认预览、保存后的当前配置和输出图片不回退到 Classic White。重复验证 Classic White 和 FilmMark。
5. 在 FilmMark 中检查样式、外观、位置与字号、底色、时间和地点等入口；记录长文本、较大文字、横竖屏和浅色/深色下的异常，不把“预览可见”当作最终输出认证。
6. 检查保存、已保存、修改后待保存、保存失败和再次保存状态；确认失败后仍可继续操作，且没有空成功或重复输出。
7. 在中文、English、日本語和한국어下检查标题、辅助说明、选择控件、保存按钮、错误状态和更新日志；覆盖 Dynamic Type、VoiceOver、Reduce Motion 和 Reduce Transparency。
8. 通过 Apple Photos 分享静态照片，验证 `Apple Photos -> Share -> MemoMark -> Processing -> Notification -> Apple Photos`；确认原始照片未被覆盖，输出确实是新的记忆照片。
9. 如测试 Live Photo，单独记录静态/动态输出类型、配对身份、EXIF/方向和 Apple Photos 读回结果；不要用静态输出结果替代动态路径结论。
