# MemoMark 2.2.2 (90) TestFlight 测试说明

> 这是测试路径材料，不表示构建 `90` 已经上传 TestFlight。

## 候选身份

- Marketing version：`2.2.2`
- Build number：`90`
- Git 基线：`c0f11a7aa36b7a3b0107b3e6003214e57376e074`
- 对比范围：`c0f11a7..current working tree`
- 重点：Configuration Center 连续性、Apple Photos 分享、本地恢复、静态照片
  和完整 Live Photo。

## 优先测试路径

### 1. 首次配置与回到配置中心

1. 首次打开 Configuration Center，确认 Memory Source、Memory Expression、
   Card Style、Card Layout And Content、Photo Description 和 Output Destination
   的信息层级完整可见。
2. 收起几个区块，离开配置中心后再次进入，确认展开状态被保留，且没有改变已
   保存的 Memory Card 配置。
3. 在 Photo Description 和 Output Destination 中进行调整，确认标题、说明和
   调整/收起操作仍位于正确的内容层级。
4. 在辅助功能字号下重复检查，确认长标题、结果和操作不会相互覆盖。

### 2. Apple Photos 分享

1. 在 Apple Photos 选择一张 JPEG 或 HEIC，分享给 MemoMark。
2. 确认分享完成后，MemoMark 能接收照片，Progress 中能看到对应任务。
3. 确认任务完成后，新的记忆照片被保存回 Apple Photos，原图仍然存在且未改变。
4. 使用一张完整 Live Photo 重复测试，确认保存结果仍可播放，并且系统相册将
   其识别为 Live Photo。
5. 在应用冷启动、重新打开或短暂进入后台后重复一次，记录是否能继续看到正确
   的任务和恢复状态。

### 3. 中断与恢复

1. 在处理期间离开应用，再次打开 Progress，确认任务状态没有伪装成成功或消失。
2. 在接近保存回相册的阶段中断，确认恢复后不会无提示地产生重复结果。
3. 在照片仍在读取时切换配置，确认该照片使用开始选择时捕获的配置。
4. 快速更换两次 Memory Subject 头像，确认较早的异步结果不会覆盖较新的选择。
5. 刷新输出相册选项时切换目标，确认过期结果不会覆盖当前保存位置。

### 4. Renderer 与卡片样式隔离回归

1. 选择 Classic White / 基础白，使用一张完整 Live Photo 输出；确认动态资源的
   底部边框为白色且包含底栏内容，没有黑色空区，并确认 Live Photo 仍可播放。
2. 切换到 Minimal / 极简，在 Card Content Editor 的 slot A 中写入一段包含文字和
   变量的组合内容；确认预览、最终输出和 Apple Photos 照片说明都显示这段用户组合
   内容，而不是右下的 Classic White 智能结果。
3. 在 Classic White 写入一段可识别内容，切换到 Minimal 写入另一段内容，再切回
   Classic White；确认两段内容各自恢复。保存配置、离开再进入后重复确认一次。
4. 对旧配置执行一次打开、保存、重新打开，确认内容没有丢失，并且之后两种样式的
   编辑内容可以分别保存；确认 Minimal 不会把旧 slot D 内容写入新照片说明。
5. 若新增 Renderer 具有两个或三个自定义内容区域，逐一确认其编辑区域、最终渲染
   区域和照片说明来源与该样式契约一致，切换到其他样式后不残留。

### 5. Card Content Editor 紧凑录入体验

1. 打开 Minimal 和 Classic White 的 Card Content Editor，确认每个区域的标题位于
   输入框左侧，四个 Classic White 区域的顺序和对应内容不变。
2. 清空一个输入区域并点入，确认插入光标在输入框内垂直居中；输入普通文字、模块及
   文字+模块后再次确认光标仍保持同一垂直中心和固定较短高度，不随内容类型跳动。
3. 插入一个智能模块，确认模块胶囊没有被 40pt 输入框裁切，光标和模块仍能在同一
   行正常编辑；在较大辅助功能字号下确认标题不会覆盖输入内容。
4. 在同一个区域组合“自定义文字 + 一个模块”，把光标放在自定义文字之后按退格，
   确认只删除文字；把光标放在两个模块之间按退格，确认只删除光标左侧的模块；在
   模块前后重复操作，确认不会跳到最右侧模块，也不会把其他模块一起删除。
5. 在上述混排内容中移动光标、切换空白/文字/模块相邻位置，确认输入框高度、光标
   垂直位置和模块胶囊基线保持稳定，标题与边框之间没有异常空隙。
6. 在同一编辑区域复制包含文字和模块的片段，再粘贴到本区域或另一个区域；确认模块仍以
   胶囊显示、顺序和组合关系不变。粘贴到其他应用时应得到可读的纯文本。
7. 插入、粘贴或删除模块后执行撤销；确认内容和光标一起回到操作前的位置。若配置中存在
   无法解析的旧模块，确认它显示为可读的警示胶囊而不是空白，并且原组合仍可复制或删除。

### 6. 设置与版本信息

1. 打开 Settings → Version，确认显示 `MemoMark 2.2.2 (90)`。
2. 打开 Settings → What's New，确认更新说明使用当前界面语言。
3. 在中文、英文、日文和韩文界面中分别打开更新说明，确认没有缺失文本或
   未翻译的内部信息。
