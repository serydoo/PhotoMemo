# TestFlight 测试说明草案：2.3.0（105）之后源码检查点

状态：`Draft`；本轮不上传 TestFlight。

本文件用于将来正式候选的测试路径整理，不代表已经产生新的归档包，也不把源码、
构建或覆盖安装证据写成外部测试通过。

## 建议测试路径

1. 在 Configuration Center 中分别编辑 FM 卡片内容、位置、底色衬托、字体、字号、
   颜色和时间/地点，观察顶部真实预览是否随草稿变化。
2. 保存后退出并重新打开配置，确认内容、外观、位置、输出位置和照片说明相关设置
   保持一致；确认没有把 FM 内容写回旧模板语义。
3. 使用 Share 路径处理一张静态照片和一组 Live Photo，分别检查通知、Apple Photos
   读回、资源身份、日期/GPS/镜头等元数据，以及原始照片未被覆盖。
4. 在进程被系统终止、重复提交、保存延迟和相册延迟可见的情况下，确认任务不会
   产生重复输出或“成功但没有结果”。
5. 在中文、English、日本語、한국어下检查长文本、不同宽高比、VoiceOver、Dynamic
   Type、Dark Mode、键盘输入和滚动路径。
6. 回归 Classic White、Minimal、Logo、头像、输出位置、照片说明、订阅权益和历史
   兼容设置，确认 FM 整理没有改变已有产品边界。
