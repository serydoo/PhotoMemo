## 面向用户的完整更新说明

这次更新让记忆对象和预设更稳定，也让照片处理完成后的结果更容易确认。

### 对象编辑与配置保持最新

- 编辑对象的名字、关系和头像后，保存、重新进入、切换对象和返回时继续显示最新内容。
- 头像裁切支持更稳定的取景、缩放和圆形预览，减少保存前后构图变化。
- 时间锚点、记忆文字、四个内容区域、输出设置和 Logo 随当前对象一起更新。
- 只有持久化成功后才更新当前界面；保存失败时保留草稿，不让旧数据覆盖新修改。

### 自选标识完整保存

- 自选标识在选择区、卡片预览和最终输出中使用一致的圆形身份标识。
- 修复自选标识保存后从小预览、卡片预览和最终呈现中消失的问题。
- 标识资源采用可携带路径保存并在运行时安全恢复，App 容器变化不会留下失效绝对路径。

### 处理结果一眼可见

- “刚刚完成”和“最近保存”现在显示最终生成结果的真实缩略图。
- 多张照片使用一张稳定代表图、轻量叠片和数量角标，不随机更换，也不在小区域加载拼贴。
- 历史封面独立于原始照片和通知附件；关闭或重新打开 App 后仍可恢复。
- 缺失封面会安全回退并自愈，不会改变任务是否已完成，也不会影响 Apple Photos 中的结果。

### 日常使用路径更清楚

- 首页在“我的预设”下方常驻简短的“怎么记录”说明。
- 日常从 Apple Photos 分享给时光记；App 内选择照片继续作为补充入口。
- App 内选择照片不再使用突兀的“备用”前缀。

## 发布边界

- `2.1.1 (77)` 没有上架，其对象切换改动和后续修复统一进入 `2.1.2 (79)`。
- 照片、头像和标识继续在设备本地处理；不修改原始照片，也不增加云端照片服务。
- 不改变 Memory Engine、Layout Engine、Renderer、PhotoKit 或 Export 的所有权边界。
- GitHub 源码同步、TestFlight 上传、App Store 提交和正式发布是四个独立状态。
- `TX-001`、`BP-001` 与历史条件性认证边界保持开放，不因本次体验修复自动关闭。
