# MemoMark 2.3.4（115）App Store“此版本的新内容”

状态：`Draft`；仅备存为同一版本文案，本轮不提交 App Store 正式版。

## 简体中文

卡片内容现在可以边编辑边看照片预览。横竖照片与完整画面的查看更方便，胶片时间文字放不下时也会给出明确提示。首页更清楚地呈现当前预设围绕的记忆对象。照片仍在设备本地处理，原图保持不变。

## U.S. English

Edit card content while keeping the photo preview in view. Landscape, portrait, and full-canvas previews are easier to inspect, and FilmMark now explains when text needs more space. The Home screen makes the Memory Object behind the current preset clearer. Photos remain processed on device, and originals stay unchanged.

## 文案边界

- 只陈述本版本可见变化与既有本地处理边界。
- 不宣称 App Store 审核、正式分发、完整设备兼容性或尚未完成的人工验收。
