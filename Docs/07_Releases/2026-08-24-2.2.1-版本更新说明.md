## 面向用户的更新

### 让一张照片拥有更轻盈的表达

- 新增「极简」卡片样式：一条安静的信息胶囊会留在照片画面内，用于呈现一段重要的回忆，而不要求四个内容区域都参与排版。
- 现在可以更清楚地区分「这一刻怎样表达」与「卡片样式」：前者决定时间锚点前后如何表达，后者决定这张照片整体怎样呈现。
- 切换「基础白」和「极简」时，已有内容与 Logo 配置会继续保留；预览、保存配置、批量任务与最终输出使用同一表达选择。

### 让动态照片按原本的方式被交还

- 静态照片继续生成静态结果；当选择保留原格式时，完整 Live Photo 会以静态帧和配对动态视频交付为新的 Live Photo。
- 如果 Live Photo 的配对信息不完整、身份无法确认或保存后的配对无法验证，任务会停在可恢复状态，不会把静态结果误报为成功的动态照片。
- 从 Apple Photos 分享、处理完成、通知返回和重新打开应用后，结果会继续围绕同一个任务保持清楚可见；原图始终不被修改。

### 让重要的日子更自然

- 年度生日在当天会表达为「今天是……岁生日」，不再被写成普通的周年倒计时。
- 结婚纪念日、关系纪念日和其他年度锚点仍按各自含义表达；输出语言继续由你为照片选择，而不是被当前界面语言覆盖。

## 工程与隐私边界

- 该版本保持本地优先：照片在设备上处理，结果作为新的照片交回 Apple Photos 管理，原图不被改写。
- Memory Engine 继续负责时间锚点语义；Layout Engine 继续负责几何；Renderer 只消费已解析的表达与布局；Share Extension 只负责接收、暂存与交接。
- 这不是云端功能、批量工作台或架构重写；Configuration Center 仍是 `Library -> Interactive Memory Card -> Object Inspector`。
