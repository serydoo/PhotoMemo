# MemoMark 2.3.0（103）App Store 文案

## 推广文本

让照片留下那一刻，也留下它在生命里的位置。MemoMark 继续以本地优先的方式，把时间、地点和重要的人生日期，整理成一张未来仍然看得懂的记忆照片。

## 此版本的新内容（简体中文）

这一版本完成了从 2.2.2 以来的核心架构整理，并优化了照片处理、队列恢复、Apple Photos 保存与记忆表达的稳定边界。MemoMark+ 现在以订阅方式提供，订阅包含全部第一方表达方式，不再对每一种表达方式重复收费；历史已获得的永久权益继续保留。照片仍在设备本地处理，原始照片不会被修改。

## What's New (U.S. English)

This release continues the behavior-preserving architecture and reliability work started in 2.2.2, with clearer boundaries across photo processing, queue recovery, Apple Photos saving, and memory expression. MemoMark+ is now offered as a subscription that includes all first-party expression styles, while previously granted permanent access remains honored. Photos are still processed on-device, and your originals are never modified.

## 口径限制

不在商店新用户文案中出现历史早鸟金额、历史标准金额或新的永久买断承诺。联名设计只有在明确标记并建立独立授权时才单独提供。
