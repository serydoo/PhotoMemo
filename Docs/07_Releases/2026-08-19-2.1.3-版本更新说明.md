# MemoMark 2.1.3 (86) 版本更新说明

## 版本与范围

- 范围起点：2026-08-14 的 `2.1.2 (85)` 同步节点，基线提交 `2dc0f21`。
- 范围终点：2026-08-19 当前工作树完成的多语言架构、主 App/Share/Widget/macOS 资源收口、交付结果修正和真机界面复核。
- marketing version：`2.1.3`。
- build number：`86`。
- 更新定位：多语言表达与用户交付可靠性维护更新；不新增云端处理，不改变原始照片保护、Memory Engine、Layout Engine、Renderer、Live Photo、EXIF、Export 或 PhotoKit 所有权边界。
- 当前状态：`Version Locked; Main Merged; Main Build Verified; Release Evidence Open`。

## 面向用户的更新

- 界面语言与照片输出语言可以独立选择。现在支持简体中文、English、日本語和한국어，配置中心、处理状态、分享入口、Widget、macOS 界面和辅助说明保持统一。
- 没有可呈现内容的照片不会再被保存成空白的成功结果；当仍有其他内容可以交付时，处理会继续进行。
- 批量处理会从用户交给 MemoMark 的照片数量开始说明结果，并区分已完成、需要处理和合理跳过的照片。
- 处理通知可以直接带你回到对应的处理状态和任务；照片仍在设备本地处理，原图保持不变，完成后生成新的记忆照片。

## 工程整理

- 建立了 Interface Language 与 Preset Output Language 的完整生命周期隔离，已有 Preset 和 Batch Snapshot 不会被当前界面语言覆盖。
- 增加结构化的时间表达和记忆叙事层，年龄、时长、倒计时、日期和锚点表达通过显式输出语言生成，不再由全局语言状态决定照片文字。
- 收口 Legacy Output 兼容链路；真实照片输出路径由 Preset/Batch Snapshot 的冻结语言决定，旧 API 仅作为显式语言 Adapter 保留。
- 完成四语言资源键集合、主 App active UI、Share Extension、Widget、macOS 和辅助说明的 parity 检查；保留未使用资源和本地研究材料，不做无证据删除。
- 修复后台诊断和通知深链路径中的 Main Actor 隔离警告；不改变通知数据流、照片处理流程或 Renderer 行为。

## 证据边界

- 已完成当前源码、资源、聚焦测试、稳定工具链构建、main 合并和合并后四个 scheme 构建；上一轮 85 已完成 iPhone 17 Pro Max 界面复核。
- 用户已明确本轮跳过 JPEG、HEIC、Live Photo、EXIF、Batch Export 媒体回归；该范围不作为本版本媒体认证结论。
