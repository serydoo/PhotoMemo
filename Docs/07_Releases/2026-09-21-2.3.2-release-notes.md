# MemoMark 2.3.2（108）版本更新说明

状态：`Version Locked; Release Evidence Open`

## 本次更新

MemoMark 2.3.2 是一次继续推进 FM（FilmMark／胶片时间）开发的体验版本，同时收拢配置中心一致性和预设样式可靠性。它从用户指定的
2.3.1 版本更新起点开始整理，当前版本号为 `2.3.2`，构建号为 `108`。

### FM（FilmMark／胶片时间）持续开发

- 本版本继续完善胶片时间的样式配置、预览关系和细节调整入口，让配置选择更接近最终呈现。
- 胶片时间与经典白、极简一样，继续沿用当前预设的样式路由，预览、保存和输出不会因为旧的处理默认而互相错位。
- FM 仍处于持续开发和 TestFlight 体验阶段；本版本不宣称完成生产认证，也不把局部预览或自动化测试等同于完整真机验收。

### 选定的卡片样式会继续保持

- 修复新建预设后，配置中心显示的样式与实际输出可能不一致的问题。
- 选择“经典白”“极简”或“胶片时间”后，当前预览、配置保存和后续输出继续使用同一选择。
- 当当前配置无法解析时，处理路径失败关闭，不再静默回退到经典白。

### 配置中心的视觉层级更统一

- 统一卡片样式、时间表达和相关配置说明的辅助文字层级，避免同一类说明出现不同字号。
- 保存主操作使用项目定义的按钮字级，和其他主要操作保持一致。
- 卡片样式选择与时间表达选择采用相同的横向空间适配策略；较大文字显示时保留可操作的选择方式。

### 保存与照片边界保持清楚

- 保存、已保存和再次保存的状态反馈继续保持可区分。
- 照片仍在设备本地处理，不上传照片，不修改原始照片；处理完成后生成新的记忆照片并按既有策略保存回 Apple Photos。
- 日常路径仍为：`Apple Photos -> Share -> MemoMark -> Processing -> Notification -> Apple Photos`。

## 应用内更新日志口径

应用内“设置 -> 更新日志”已同步更新中文、English、日本語和한국어文案。普通用户文案只描述
可见体验与照片边界，不包含 Git、Xcode、测试数量、内部风险编号或未完成的外部发布证据。

## 本轮范围边界

- 版本范围起点：用户指定的 `2.3.1`；仓库中未发现可独立确认的 2.3.1 正式候选材料，因此不虚构 2.3.1 的构建号或外部发布状态。
- 本轮正式同步候选：配置中心 UI 规范修复、当前配置选择解析修复的既有维护范围、对应回归测试、四语言资源、版本字段和本组版本材料。
- 本地保留：`Docs/Outreach/`、私人照片、设备截图、签名产物、归档包、DerivedData、Xcode 状态和 `/tmp` 诊断材料。
- 不在本轮声明：真机逐屏视觉/VoiceOver/Dynamic Type/Photos/Share/Live Photo 手工验收、StoreKit 验证、TX-001、BP-001、Xcode Cloud 归档、TestFlight 上传、App Store 提交或正式发布。

## 当前停止点

源码、测试、版本字段和发布材料仅完成本地准备。未执行 `git add`、commit、push、TestFlight 上传或
App Store Connect 修改；这些动作需要单独授权。
