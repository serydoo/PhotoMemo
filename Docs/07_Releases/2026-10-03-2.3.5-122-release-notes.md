# MemoMark 2.3.5（122）版本总表与更新说明

版本：2.3.5（122）。范围起点：负责人指定的正式版 2.3.4（115）；相邻源码基线 `45466834c84313aa4d71bf92a6cb8f2691a1b341`。正式版身份来自负责人，本轮未查询商店发布状态。

状态：Version Locked; Release Evidence Open。GitHub 提交／推送已授权；负责人后续授权 Cloud 成功后发布 TestFlight；当前未执行分发或 App Store 提交。

这次更新让记忆卡预览与设置更自然，也继续完善极简表达。

- 配置中心支持显示或收起预览；编辑卡片内容时，预览会重新显示，完成编辑后恢复原来的选择。重新启动应用默认显示预览。
- 调整预览标题与照片之间的留白，缩小方向切换和查看照片按钮的视觉尺寸，同时保留 44pt 触控区域。
- 整理设置页层级；介绍、使用帮助和更新日志可通过系统返回导航回到设置。
- 优化时间锚点、预设备份、卡片编辑与语言选择的中英日韩文案和自适应控件。
- 改善极简长文字和首页预设说明的宽度适配，修复 JPEG 多语言说明保存及 Live Photo 关键帧时间信息保留问题。

照片继续在设备本地处理，原图保持不变；保存的是新的记忆照片。

GlassCard 原生材质、共享预览和静态／动态开发路径已接通；Release 新建选择入口仍关闭，既有配置保持可处理。不得宣传为正式开放功能。HDR／P3、广泛性能、Photos 人工播放与无障碍验收尚需独立证据。此前 116 测试与设备记录仅作历史参考，122 验证见同步清单。
