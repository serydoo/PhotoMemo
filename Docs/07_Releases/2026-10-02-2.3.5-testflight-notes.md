# MemoMark 2.3.5（116）TestFlight 测试说明

状态：Draft。本轮未上传或分发TestFlight。Release构建不提供GlassCard新建选择入口，不能让普通测试者寻找不存在的选项。GlassCard专项验证使用获授权的Debug设备入口或已有配置；不要为测试扩大正式入口。

## 常规测试

1. 覆盖安装116，核对版本、已有对象、预设、语言和配置可恢复。
2. Minimal输入较长中英文，核对横竖照片的预览、静态输出与单一表达；原照片不变。
3. 首页选择说明较长的预设，在普通字号检查说明一行优先和勾选位置；辅助功能大字号检查多行阅读及VoiceOver完整标签。
4. JPEG输出中文、日文、韩文和emoji说明，核对EXIF UserComment及新输出；保存失败应明确报告。
5. 继续从Apple Photos分享静态／Live Photo，记录新增资源、声音、方向、恢复和通知路径；不能以静态结果代替动态验收。

## GlassCard有界专项

使用开发验证入口分别检查明暗、复杂纹理、横竖图；原生玻璃会随每帧背景变化，文字和Logo保持在上层。检查静态封面与长按开始／结束的裁切、面板位置、可读性、闪烁、声音和流畅度。核对新配对身份及Photos读回。当前输出为SDR，视频尺寸受编码预设限制；HDR／P3和广泛设备性能仍待专项结论。正式入口开放属于后续产品验收决定。

反馈：设备／OS／语言／外观／字号／版本、样式和照片类型、输入长度、操作步骤、预期实际、是否可恢复。请移除人物隐私、精确位置、私密照片和设备标识；测试照片留在设备上。
