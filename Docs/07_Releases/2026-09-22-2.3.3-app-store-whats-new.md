# MemoMark 2.3.3（109）App Store “此版本的新内容”

状态：`Draft`；用于后续 App Store Connect 版本页面，尚未提交。

## 简体中文

继续完善胶片时间（FilmMark）和记忆卡配置体验。现在，你选择的经典白、极简或胶片时间样式会更可靠地延续到预览、保存和新的记忆照片中；配置中心的保存反馈和较大文字下的操作也更清楚。照片继续在设备本地处理，原始照片不会被修改。

## U.S. English

We continued refining FilmMark and Memory Card configuration. The Classic White, Minimal, or Film Time style you choose now carries more reliably through preview, saving, and each new memory photo, with clearer save feedback and interaction at larger text sizes. Photos continue to be processed on device, while originals remain unchanged.
