# MemoMark 2.3.3（111）App Store “此版本的新内容”

状态：`Draft`；用于后续 App Store Connect 版本页面，尚未提交。

## 简体中文

从 2.3.0 开始，MemoMark 持续完善经典白、极简和胶片时间（FilmMark）三种展示方式。FilmMark 带来更丰富的自定义空间，可以调整样式、内容、位置、字号、底色、时间和地点；记忆对象与时间锚点也重新整理，让从选择到保存的记忆表达更贴近你。照片继续在设备本地处理，原始照片不会被修改。

## U.S. English

Since 2.3.0, MemoMark has continued refining three ways to shape a memory photo: Classic White, Minimal, and FilmMark. FilmMark gives you more room to customize style, content, placement, type size, substrate, time, and location, while Memory Object and Time Anchor editing are easier to organize. Photos continue to be processed on device, while originals remain unchanged.
