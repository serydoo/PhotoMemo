# MemoMark 2.3.6 (124)

## zh-Hans

这次更新补上永久解锁入口，并改善 Live Photo 保存与记忆卡片呈现。

选择适合你的使用方式

在订阅下方新增永久解锁选项，购买或领取后可恢复永久权益。

价格由 App Store 显示；已有订阅的续订仍需在 Apple 订阅设置中管理。

记忆卡片更清楚

改善玻璃卡片的文字间距、内容排列与呈现细节。

调整配置时的预览与底部操作，让查看和编辑更自然。

安心保存这段回忆

修复部分 Live Photo 保存失败的问题，并改善重试提示。

照片仍在本地处理，原图保持不变；完成后保存新的记忆照片。

Clearer Memory Cards

Fixed saving failures for some Live Photos and clarified retry guidance.
