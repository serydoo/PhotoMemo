# MemoMark 2.3.5（122）TestFlight 测试说明

版本：2.3.5（122）。范围起点：负责人指定的正式版 2.3.4（115）；相邻源码基线 `45466834c84313aa4d71bf92a6cb8f2691a1b341`。正式版身份来自负责人，本轮未查询商店发布状态。

本轮准备材料，尚未上传／分发。

1. 从已有版本覆盖安装 122，核对预设、记忆对象、时间锚点、语言与购买权益；不要卸载清空数据。
2. 配置中心收起／显示预览，切换页面后检查选择保留；收起后进入卡片编辑，确认预览显示，退出编辑恢复收起；重启默认显示。
3. 横竖照片检查标题留白、方向切换、缩放与触控；中英日韩、辅助功能字号、VoiceOver、减少动态效果分别记录。
4. 设置中打开表达帮助、关于、使用方式、欢迎页与更新日志，再返回；欢迎页进入使用方式后应先回欢迎页，再回设置。检查展开状态保持。
5. Minimal 较长文字、首页预设说明、时间锚点编辑、备份与语言菜单，核对内容不丢失，取消／保存行为明确。
6. Apple Photos 分享静态与 Live Photo，核对新资产、方向、声音、关键帧封面／播放、通知和保存失败恢复；确认原图不变。
7. JPEG 中文、日文、韩文和 emoji 说明保存，核对新资产的说明。

GlassCard Release 新建入口关闭，不要求测试者寻找该选项。已有配置或获授权 Debug 专项才验证原生玻璃；SDR、HDR／P3、长片段性能需分别记录。

反馈请提供版本、设备／系统、语言／字号／外观、照片类型、操作步骤、预期与实际、是否可恢复。照片留在设备，反馈移除人物隐私、精确位置与设备标识。
