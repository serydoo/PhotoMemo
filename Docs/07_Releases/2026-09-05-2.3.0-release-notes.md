# MemoMark 2.3.0（103）版本更新说明

状态：`Version Locked; Release Evidence Open`

## 这次更新带来了什么

2.3.0 是 MemoMark 在 2.2.2、2.2.3 和 2.2.4 连续维护与重构之后的商业与产品边界更新。它继续保持本地优先、原始照片不被修改、Apple Photos 作为照片归属地的核心承诺，并把 MemoMark+ 的权益表达改得更清楚。

- 配置、队列、媒体保存和界面责任继续沿行为保持的架构边界整理，降低后续维护对照片生命周期和记忆真实含义的影响。
- 历史上已经完成购买或获得激活权益的用户继续保有原有永久核心权益，包括无限记录、批量处理和全部第一方表达方式。
- 新用户不再看到历史永久购买入口，MemoMark+ 改为自动续订订阅；App Store 的本地化价格与周期是唯一价格来源。
- MemoMark+ 订阅一次性包含全部第一方表达方式，不会在订阅之外再按表达方式重复收费。
- 免费体验聚焦于一个记忆对象、一个时间锚点和自然表达；查看、保存已有记忆以及本地处理基础照片不因商业状态变化而被删除。
- 未来明确标记为联名或合作的设计可以独立授权，但不会影响 MemoMark+ 的核心能力和第一方表达方式。
- 订阅有效期现在进入共享权益快照，Share Extension 不会把已过期订阅误认为永久权益。

## 权益名称

- 历史已获得权益：`MemoMark+ 永久权益`；已有身份记录的用户同时显示 `MemoMark 首批记录者`。
- 当前有效订阅：`MemoMark+ 订阅会员`。
- TestFlight / Sandbox 临时状态：仅用于测试，不会迁移为正式版权益。

本版本的新用户文案不再宣传历史价格或新的永久买断。历史账户只在账户状态成立时显示与其真实权益相符的永久说明。

## 隐私与平台边界

照片仍在设备本地处理，原始照片不被修改，输出是新的记忆照片。购买与恢复由 Apple StoreKit 管理；MemoMark 不上传照片，也不把订阅身份当作照片云端服务。

## 证据边界

本文件描述源码候选的目标范围。macOS Debug 构建已经通过；StoreKit Sandbox、实体 iPhone、Xcode Cloud 归档、App Store Connect 商品与商店分发状态必须以各自的独立证据记录，不能由 Git 提交或本地构建推断。
