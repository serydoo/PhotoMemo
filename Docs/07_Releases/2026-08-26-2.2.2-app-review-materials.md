## 审核说明（English）

```text
Thank you for reviewing MemoMark 2.2.2 (build 90).

MemoMark is a local-first memory presentation app for Apple Photos. It does not require an account, login, or demo credentials. Normal operation does not require server communication. Photos selected by the user are processed on the device, the original photo is not modified, and MemoMark saves a new memory photo back to Apple Photos.

How to test the core workflow:
1. Open Apple Photos and select one JPEG or HEIC photo. A complete Live Photo can also be used for the motion-preserving path.
2. Share the photo to MemoMark.
3. If prompted, allow the Photos permission needed to receive the shared photo and save the new result.
4. If this is the first launch, follow the in-app setup to create one Memory Subject, choose a time anchor, and save the configuration.
5. Open Card Content Editor, confirm that the region title is placed beside its input field, and optionally enter a short custom phrase or insert a smart module. The empty field should accept focus normally; this is only a presentation check and does not change the photo workflow.
6. For the editor interaction check, combine a short custom phrase with two modules. Backspace after the phrase should remove the adjacent text; backspace between modules should remove only the module immediately to the left of the caret, not the rightmost module. The input row should keep a stable height and caret baseline.
7. Return to MemoMark and open Progress if needed. Confirm that the task is received, processed locally, and completed.
8. Open Apple Photos and confirm that the new memory photo is present. The original asset remains unchanged.

The optional MemoMark+ purchase is a non-consumable product. No purchase is required to review the core local photo workflow. If the purchase path is reviewed, it is available from Settings → MemoMark+ and uses StoreKit 2 product ID com.serydoo.PhotoMemo.iOS.memomarkplus.lifetime. Restore Purchases is available on the same page.

MemoMark does not upload photos, does not include user accounts, and does not use third-party advertising or tracking. Shared settings and processing state remain in the app container or App Group on the device.
```

## 审核说明（中文留档）

```text
感谢审核 MemoMark 2.2.2（构建 90）。

MemoMark 是一款围绕 Apple Photos 的本地优先记忆呈现应用。不需要账号、登录或测试账号，正常使用不依赖服务器通信。用户主动选择的照片在设备本地处理，原始照片不会被修改，MemoMark 会把新的记忆照片保存回 Apple Photos。

核心测试方式：
1. 打开 Apple Photos，选择一张 JPEG 或 HEIC；也可以使用一张完整 Live Photo 测试动态照片路径。
2. 将照片通过系统分享菜单分享给 MemoMark。
3. 如果系统提示，请允许接收分享照片并保存新结果所需的照片权限。
4. 如果是首次打开应用，按页面提示建立一个 Memory Subject、选择时间锚点并保存配置。
5. 打开 Card Content Editor，确认区域标题位于输入框左侧；可以输入一小段自定义文字或插入一个智能模块。空白输入框应能正常获得焦点，这只是界面检查，不改变照片处理流程。
6. 在同一个区域组合一小段自定义文字和两个模块：文字后的退格只删除相邻文字，两个模块之间的退格只删除光标左侧模块，不应跳到最右侧模块；输入框高度和光标基线应保持稳定。
7. 复制包含文字和模块的片段并粘贴，确认模块身份与顺序保留；插入、粘贴或删除模块后执行撤销，确认内容和光标恢复。若出现无法解析的模块，确认仍显示为可读的警示胶囊。
8. 返回 MemoMark，必要时打开 Progress，确认任务被接收、在本机处理并完成。
9. 回到 Apple Photos，确认新的记忆照片已经出现，原始照片保持不变。

MemoMark+ 是可选的非消耗型买断商品。审核核心本地照片流程不需要购买。如果审核购买路径，可从 Settings → MemoMark+ 进入，StoreKit 2 商品 ID 为 com.serydoo.PhotoMemo.iOS.memomarkplus.lifetime；同一页面提供恢复购买。

MemoMark 不上传照片，不包含用户账号，不使用第三方广告或跟踪。共享配置和处理状态只保存在设备上的 App 容器或 App Group 中。
```

## Review 可能需要的说明

### Photo Library 权限

权限用于接收用户主动分享的照片，以及将新的处理结果保存回 Apple Photos。应用
不会将照片上传到远程服务，也不会修改用户选择的原始资产。

### 账号与网络

没有账号注册、登录或测试账号。核心照片流程以本地处理为基础；App Store
购买路径由系统 StoreKit 处理，商店可用性以 Apple 服务实际返回为准。

### MemoMark+ / IAP

- 类型：Non-Consumable
- 商品 ID：`com.serydoo.PhotoMemo.iOS.memomarkplus.lifetime`
- 应用内入口：`Settings → MemoMark+`
- 不需要购买即可检查核心照片分享和本地处理流程。
- 商品价格、审核截图、税务、Paid Apps Agreement 和 Production 交易状态必须
  在 App Store Connect 侧单独确认。

### App Privacy 与 Export Compliance 留档

- App Privacy：按当前产品行为核对为“不收集数据”；不用于跟踪，不包含第三方广告。
  若 App Store Connect 的问卷或最终二进制行为有变化，以实际提交版本为准重新填写。
- Export Compliance：当前应用的核心功能在设备本地处理照片，不提供 VPN、通用文件
  加密或网络加密服务；提交前仍需依据 App Store Connect 对最终二进制的问卷逐项确认，
  不把本段留档直接替代 Apple 的正式申报。
- Review attachments：如需补充截图或视频，只使用公开测试照片，不包含私人照片、人物、
  地点、EXIF、设备 UDID、诊断导出或本地路径。
