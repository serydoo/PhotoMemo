## App Review Notes（English）

```text
Hello App Review Team,

Thank you for reviewing MemoMark 2.2.2 (build 99).

MemoMark is a local-first memory presentation app built around Apple Photos. It does not require an account, login, or demo credentials, and the core photo workflow does not require server communication. Photos selected by the user are processed on the device, the original asset is not modified, and MemoMark saves a new memory photo back to Apple Photos.

Core review path:
1. Open Apple Photos and select one JPEG or HEIC photo. A complete Live Photo may also be used to review the motion-preserving path.
2. Use the system Share sheet to share the photo to MemoMark.
3. If prompted, grant the Photos permissions needed to receive the shared photo and save the new result.
4. On first launch, follow the in-app setup to create a Memory Subject, choose a time anchor, and save the configuration.
5. Open Card Content Editor. Review an empty field, plain text, punctuation, a module, and a mixed text-and-module line. Insert, delete, and reorder modules before, after, and between text. The input row keeps a stable height and the text and caret remain aligned.
6. Optionally copy and paste a mixed line, then use undo to confirm that text, module order, and the local caret position are preserved.
7. Return to MemoMark and open Progress if needed. Confirm that the photo is received, processed locally, and completed.
8. Open Apple Photos and confirm that a new memory photo is present. The original asset remains unchanged.

The optional MemoMark+ purchase is a non-consumable product. No purchase is required to review the core local photo workflow. If the purchase path is reviewed, it is available from Settings → MemoMark+ and uses StoreKit 2 product ID com.serydoo.PhotoMemo.iOS.memomarkplus.lifetime. Restore Purchases is available on the same page.

MemoMark does not upload photos, does not include user accounts, third-party advertising, or tracking. Shared settings and processing state remain in the app container or App Group on the device.
```

## 审核说明（中文留档）

```text
MemoMark 是一款围绕 Apple Photos 的本地优先记忆呈现应用，不需要账号、登录或测试账号。用户选择的照片在设备本地处理，原始照片不会被修改，应用会把新的记忆照片保存回 Apple Photos。

审核时可以从 Apple Photos 选择 JPEG、HEIC 或完整 Live Photo，通过系统分享菜单发送到 MemoMark；首次打开时建立记忆对象、选择时间起点并保存配置。进入卡片内容编辑器后，可依次检查空白、纯文字、标点、单个模块以及文字与模块混排，并在模块前、后、夹中插入、删除和重新排列模块。输入框高度、文字和光标应保持稳定。

完成处理后回到 Apple Photos，确认出现新的记忆照片，同时原始照片保持不变。MemoMark+ 为可选的非消耗型买断，不购买也可以审核核心照片流程。
```

## 权限、隐私与购买说明

- Photos 权限仅用于接收用户主动分享的照片，以及保存新的处理结果；原始资产不被修改。
- 没有账号注册、登录或测试账号，核心照片流程不依赖远程服务。
- 不上传照片、不使用第三方广告或跟踪；配置和处理状态仅保存在设备 App 容器或 App Group。
- `MemoMark+` 为可选 Non-Consumable 商品，入口为 `Settings → MemoMark+`；价格、审核截图、Paid Apps Agreement 与 Production 交易状态以 App Store Connect 为准。
- App Privacy 与 Export Compliance 必须按最终上传二进制在 App Store Connect 中逐项确认；本文件不替代 Apple 的正式问卷。
- 审核截图或附件只使用公开演示资料，不包含私人照片、真实姓名、地点、EXIF、设备 UDID、诊断导出或本地路径。
