## 这段时间持续完善了什么

### 1. 让每种表达方式拥有自己的内容边界

从 2.3.0（105）开始，Classic White、Minimal 和 FilmMark 的内容、预览和输出关系持续拆清。Minimal 不再借用 Classic White 的区域语义；FilmMark 继续使用独立的内容、外观、位置和布局关系。预览和新的记忆照片都围绕用户当前选择的表达方式展开。

### 2. 让配置中心的选择可靠地延续到结果

- 修复新建或编辑 Preset 后，配置中心显示的样式与实际处理结果可能不一致的问题。
- 当前配置能够解析时，处理路径使用同一份不可变配置快照；无法确认时失败关闭，不悄悄回退到 Classic White。
- 统一卡片样式、时间表达和保存反馈的层级，并改善较大文字下的选择路径。
- macOS Configuration Center 继续保持真实 Memory Card 预览和 Inspector 编辑结构；这些平台整理不改变 iOS 的共享持久化和 PhotoKit 边界。

### 3. FilmMark 继续从研究走向可验证的表达关系

FilmMark 的样式配置、预览、位置与字号、底色和内容关系继续收口。它仍然是持续开发中的表达方向，不在本版本中宣称完成生产认证；局部自动化测试或预览观察也不替代真机输出读回。

### 4. 保持照片和本地处理边界

照片继续在设备本地处理，原始照片不会被修改；每次处理产生新的记忆照片，并按既有流程回到 Apple Photos。Share、Processing、Notification、静态照片、Live Photo、EXIF 和相册读回仍分别接受平台环境验证。

### 5. 维护语言、可访问性和长期一致性

本候选同步更新简体中文、English、日本語和한국어的应用内更新日志，并继续维护配置中心的本地化键集合、较大文字布局和系统原生交互边界。

## 面向用户的更新重点

- 选择 Classic White、Minimal 或 FilmMark 后，预览、保存和新的记忆照片更可靠地保持同一选择。
- 配置中心的样式、时间表达和保存状态更容易理解。
- FilmMark 继续获得样式、预览和细节调整方面的改进。
- 照片仍在设备本地处理，原始照片保持不变。
