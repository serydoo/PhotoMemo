## 从 2.3.0 到现在，我们持续完善了什么

### 1. 三种展示框架，分别拥有自己的表达方式

从 2.3.0（105）开始，MemoMark 持续完善经典白、极简和胶片时间（FilmMark）三种展示框架。它们不再只是颜色或外观的变化，而是各自拥有清晰的内容、布局和视觉关系。你选择的表达方式，会继续贯穿预览、保存和新的记忆照片。

### 2. FilmMark 带来更大的自定义空间

FilmMark 已从早期的表达研究，逐步形成独立的样式、内容、位置和布局关系。当前可以围绕记忆自由调整样式、内容、位置、字号、底色、时间和地点等细节，让同一段记忆拥有更贴近个人感受的呈现方式。根据本版本发布决定，FilmMark 随 `2.3.3 (111)` 进入正式用户版本；`BP-001`、`TX-001` 和指定 iPhone 17 Pro Max FilmMark 全链路已按范围完成初步关闭，后续反馈仍可补充或重新打开。详见 `Docs/01_Product/V4_FilmMark_2.3.3_111_Initial_Production_Closure_2026-09-23.md`。

### 3. 配置中心重新组织了从选择到结果的关系

配置中心持续围绕真实的 Memory Card 展开。记忆对象、预设、预览、保存和最终照片之间的关系更清晰，所选样式会更可靠地延续到结果；当前配置无法确认时，不会悄悄切换到另一种样式。

### 4. 记忆对象与时间锚点更容易整理

重新整理记忆对象的细节编辑，让人物信息、称呼和关系更容易维护；时间锚点也支持在对象编辑界面中明确调整顺序、删除和继续添加示例。重要的人和日子不再只是配置项，而是更容易成为记忆表达的一部分。

### 5. 保持照片和本地处理边界

照片继续在设备本地处理，原始照片不会被修改；每次处理产生新的记忆照片，并按既有流程回到 Apple Photos。Share、Processing、Notification、静态照片、Live Photo、EXIF 和相册读回仍分别接受平台环境验证。

### 6. 维护语言、可访问性和长期一致性

本候选同步更新简体中文、English、日本語和한국어的应用内更新日志，并继续维护配置中心的本地化键集合、较大文字布局和系统原生交互边界。

## 面向用户的更新重点

- 三种展示框架各自拥有清晰的表达方式：经典白、极简和胶片时间（FilmMark）。
- FilmMark 提供更丰富的自定义空间，可以调整样式、内容、位置、字号、底色、时间和地点等细节。
- 配置中心、记忆对象和时间锚点重新组织，从选择、预览到保存的关系更清楚。
- 照片继续在设备本地处理，原始照片保持不变，并生成新的记忆照片。
