# MemoMark 2.2.1 (90) TestFlight 测试说明

> 本文件定义候选构建的测试路径；当前不表示 TestFlight 已上传。

## 候选信息

- marketing version：`2.2.1`
- build number：`90`
- 测试重点：卡片样式与预览一致性、Live Photo 媒体真实性、时间锚点语义、Apple Photos 交接与本地处理边界。

## 优先测试路径

### 1. 卡片样式与配置中心

1. 在 Configuration Center 的「卡片样式」中选择「极简」，确认预览显示画面内的悬浮信息胶囊。
2. 保存后退出并重新进入，确认「极简」选择、Logo 与内容仍被保留。
3. 切回「基础白」，确认原有其他内容区域仍在，不会因样式切换丢失。
4. 分别使用横向、纵向照片、长中文/English 文本及 Dynamic Type，检查预览和最终结果是否有遮挡、裁切或不一致。

### 2. 静态照片与 Live Photo

1. 选择 JPEG/HEIC 并使用 `originalFormat`，确认结果为新的静态照片，原图保持不变。
2. 从 Apple Photos 分享完整 Live Photo，使用 `originalFormat`，确认结果可播放，且 still 与 paired video 作为同一新的 Live Photo 保存。
3. 选择 `staticImage` 后处理 Live Photo，确认这是唯一允许输出静态结果的路径。
4. 使用缺少 paired video、still 或 identity 的测试样本，确认任务进入可恢复失败，而不是显示为静态成功。
5. 完成后关闭并重新打开应用，确认任务、保存结果与失败状态不会被重复处理或静默改写。

### 3. 时间锚点与本地交付

1. 在生日当天生成结果，确认显示自然的生日当天表达；在临近生日时确认显示倒计时。
2. 检查结婚纪念日、关系纪念日和自定义年度锚点不会混用生日语义。
3. 切换界面语言与照片输出语言，确认已保存配置的照片输出语言不被界面语言覆盖。
4. 从 Apple Photos 通过 Share 交给 MemoMark，确认处理通知可回到对应任务，新结果写回 Photos，原图没有被覆盖。

### 4. 中断、恢复与重复处理

1. 分享照片后，在处理过程中退出 App，再次打开进展页面，确认任务仍然存在并能继续处理。
2. 在结果即将写回 Apple Photos 时终止 App，再次打开后确认不会重复生成同一张结果。
3. 观察处理失败、可重试和已完成状态，确认诊断信息、进度与状态不会互相矛盾。
4. 如果系统相册权限、目标相册或本地空间暂时不可用，确认界面提供明确的恢复路径，而不是显示为已经完成。
