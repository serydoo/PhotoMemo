# MemoMark 2.1.3 (86) TestFlight 测试说明

## 本轮重点

请优先检查以下路径：

1. 在简体中文界面中，将 Preset Output Language 分别设为简体中文、English、日本語和한국어，确认设置页/配置中心仍使用界面语言，而照片预览和新生成文字使用输出语言。
2. 在 English 界面中选择日本語输出；在日本語界面中选择한국어输出，确认切换界面语言后，已经保存的 Preset 和任务输出语言不变。
3. 进入 Task / Processing 页面，检查日本語和한국어下的标题、状态、按钮、Picker、导航标题和错误恢复说明。
4. 在 Settings -> Recent Updates 查看 `2.1.3 (86)` 更新说明，确认四种界面语言都能读取完整内容。
5. 观察单张和批量处理结果：没有可呈现内容的照片不能形成空白成功结果；一张照片需要处理时，其他照片仍可继续。
6. 点击处理通知，确认能够回到对应的处理状态和任务。

## 反馈格式

请提供：设备型号、系统版本、界面语言、Preset Output Language、入口路径、是否为单张/批量，以及发生问题时的可见文案或截图。请不要上传私人照片、原始文件、路径或包含人物/地点信息的诊断材料。

## 本轮边界

- 本轮重点是多语言架构与用户可见界面/交付状态。
- JPEG、HEIC、Live Photo、EXIF、Batch Export 媒体回归按用户决定跳过，不作为本轮 TestFlight 结论。
- 这份说明不代表 TestFlight 已上传；上传、商店提交和生产认证需要单独授权与证据。
