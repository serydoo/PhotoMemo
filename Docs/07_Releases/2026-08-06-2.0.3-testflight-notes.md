# MemoMark 2.0.3 (70) TestFlight 测试说明

状态：`Version Locked; Release Evidence Open`

目标版本与构建号：`2.0.3 (70)`

## 本次测试内容

本次测试版重点检查更自然的时间表达、配置中心的紧凑体验、系统外观，以及保存回 Apple Photos 后的恢复一致性。

- 时间关系按照片拍摄时区中的日历日判断，跨过该日历的零点即进入下一天。
- 生日当天使用自然表达，不再显示 `0天` 或 `0 days`。
- 记忆表达可以预览 `之前 / 当天 / 之后` 三种状态。
- 配置中心、下级编辑页和照片说明卡片的文字、层级与小屏显示更加清楚。
- 设置支持 `跟随系统 / 浅色 / 深色` 三种界面外观，照片输出不受影响。
- 静态照片和 Live Photo 保存后的恢复与重复结果保护得到改进。

## 建议重点验证

### 1. 时间表达

1. 为记忆对象设置生日锚点。
2. 选择一张拍摄日期与生日锚点属于同一日历日的照片，拍摄时间早于或晚于锚点时间均可。
3. 确认完整表达自然显示“今天来到这个世界啦”，年龄结果显示“出生当天”，不出现“0天”。
4. 切换不同表达方式，确认重要时刻之前、当天和之后的预览会同步变化。
5. 选择非生日锚点：验证跨零点后进入下一天；同一日内早晚不同的时刻不会仅因时分先后变成倒计时。
6. 切换英文界面，确认对应结果不会显示 “0 days”。

### 2. 配置与照片说明

- 在紧凑宽度 iPhone、普通字号和较大字号下检查记忆来源、时间锚点、记忆表达、Logo 标识和更多信息。文字与操作不应被截断。
- 检查时间锚点、更多信息和卡片内容页面：标题、说明、选择和保存操作应清楚且可完成。
- 打开保存页面，确认 `新照片`、`照片说明` 和 `回到哪里` 是三个清楚的独立区域。
- 开启自定义照片说明后，确认完整记忆表达仍会保留，补充文字会在下一行显示，也不替换表达。

### 3. 界面外观与辅助功能

- 依次切换 `跟随系统 / 浅色 / 深色`，确认首页、配置、处理、输出、设置和下级页面能正确显示；重启 App 后选择应保留。
- 在深色下检查卡片、文字、选择器、弹窗和输入控件的对比度；不应出现内容消失、白底白字或大块黑色遮挡。
- 检查较大 Dynamic Type、VoiceOver 和“减少动态效果”：文字和操作应完整可读、可朗读，展开或收起照片说明时不应出现多余位移动画。
- 保存一张结果，确认界面外观没有改变最终照片的颜色或文字。

### 4. Apple Photos 保存与恢复

- 分别用一张静态照片和一张 Live Photo 完成 `Apple Photos -> 分享 -> MemoMark -> 保存回 Apple Photos`。
- 确认每次操作只产生一个新结果，原始照片不变；Live Photo 结果可在 Apple Photos 中长按播放。
- 在保存阶段尽可能快速终止 MemoMark，然后立即重启，观察任务恢复和 Apple Photos 中的结果数量。
- 如果结果已出现在 Apple Photos，重启后任务应完成且不再次渲染或保存；如果结果暂未显示，MemoMark 不应立即创建替代结果。
- 恢复成功后再重启两到三次，确认完成状态和结果数量保持稳定。
- 当照片权限在恢复期间发生变化时，确认 App 给出可理解的权限或恢复提示，并且不创建重复结果。

请记录静态照片与 Live Photo 的实际结果。Apple Photos 对照片说明的显示和搜索可能因 iOS 版本与照片类型而不同，未显示不一定代表没有写入。

## 反馈方式

请通过 TestFlight 的“发送 Beta 版反馈”提交问题，并尽量附上：

- 出现问题的页面与操作步骤；
- 设备型号、iOS 版本和当前界面语言；
- Dynamic Type 或 VoiceOver 是否开启；
- 能说明布局或恢复过程的截图或屏幕录制；
- Apple Photos 中本次操作前后的结果数量。

无需提交私人原始照片、人物信息、地点、文件名或完整资产标识。保存失败时可提供 App 显示的简短支持编号和大致发生时间。

## 已知验证边界

- 真机上的强制终止、Apple Photos 延迟显示和恢复后的结果数量，是本轮优先验证项目；普通保存成功不能替代这些证据。
- 系统外观、较大字号、VoiceOver、英文和照片说明的显示仍需要在实际 TestFlight 候选包上复核。
- Apple Photos 的照片说明显示和搜索属于系统兼容性边界，本测试版不承诺不同 iOS 版本和照片类型完全一致。
- 当前测试用于收集真实设备证据，不代表所有生产可靠性验证已经完成。
