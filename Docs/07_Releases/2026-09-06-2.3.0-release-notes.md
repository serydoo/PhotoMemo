# MemoMark 2.3.0（104）版本更新说明

状态：`Version Locked; Release Evidence Open`

## 这次更新带来了什么

2.3.0（104）在 2.2.2 以来的行为保持重构、稳定性优化和 103 商业模型候选基础上，继续收敛 MemoMark 的正式发布边界。它保持本地优先、原始照片不被修改、Apple Photos 作为照片归属地的核心承诺，并让新用户更容易理解日常使用路径。

- 继续保留历史已购买或已激活用户的真实永久权益，包括其原有的完整记录能力和第一方表达方式；历史权益不会被后续订阅状态覆盖。
- 新用户使用 MemoMark+ 订阅，提供月度与年度两种周期；一次订阅开放全部第一方表达方式，不会为每一种表达方式再次收费。联名或合作设计可以在未来以独立授权提供。
- 免费商业额度保持既有规则；“累计使用主页选图入口 10 次”只是使用引导触发条件，不是免费处理次数，也不改变照片处理或记忆记录额度。
- 主页的“选择图片”入口始终保留。累计成功进入选图流程 10 次后，主页显示一次“调整使用引导”提示；提示打开设置中的“日常使用流程”，展示 24 小时后自动从主页收起。
- 时间锚点建议以非持久化示例呈现；用户可以先预览，只有添加、编辑或自定义时才进入相应的权益判断。建议文案与新增锚点路径已纳入中、英、日、韩本地化。
- StoreKit 现在按完整当前权益重新计算快照，并保留历史永久权益优先级；月度与年度商品均可被识别，商品缺失时不会把购买页错误地固定在不可用周期。

## 权益名称

- 历史已获得权益：`MemoMark 首批记录者` 或 `MemoMark+ 永久权益`，按真实历史来源显示。
- 当前有效订阅：`MemoMark+ 订阅会员`。
- TestFlight / Sandbox 临时状态：仅用于测试，不会转化为正式永久权益。

本版本的新用户文案不宣传历史价格或新的永久买断。历史账户只在账户状态成立时显示与其真实权益相符的永久说明。

## 隐私与平台边界

照片仍在设备本地处理，原始照片不被修改，输出是新的记忆照片。购买与恢复由 Apple StoreKit 管理；MemoMark 不上传照片，也不把订阅身份当作照片云端服务。
