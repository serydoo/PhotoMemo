# MemoMark 2.3.0（105）TestFlight 验证说明

本文件只用于 2.3.0（105）候选验证，不代表 App Store 正式发布或审核通过。

## 测试重点

1. 用新测试账户确认 MemoMark+ 月度与年度订阅的购买、待处理、恢复、到期和
   重新计算路径。
2. 用历史购买账户和持有历史 48 元永久会员激活码权益的账户确认重装、恢复和
   后续订阅事件不会降低永久权益；确认激活码权益与历史购买权益的能力一致。
3. 切换 Classic White 与 Minimal，分别编辑、保存、重新加载并预览内容；确认
   Minimal 的内容不会意外读取 Classic White 的 A/D 语义。
4. 分别验证两种样式的 Apple Photos 照片说明来源：Classic White 使用其记忆
   内容，Minimal 使用其唯一的极简输出内容。
5. 在 iPhone 17 Pro Max 竖屏和横屏验证头像裁切的放大、拖拽、双指缩放、恢复
   默认位置、取消和完成；确认结果同时反映在对象头像与卡片预览。
6. 验证 Logo 标识的系统默认、自定义图片选择、裁切/缩放、替换和恢复默认；确认
   自定义图片不会改变原始照片，也不会影响卡片输出以外的资源。
7. 在手机横屏打开 Minimal 配置预览，确认预览占用紧凑横屏可用宽度；切回
   Classic White、竖屏和页面滚动后确认布局没有互相污染。
8. 覆盖简体中文、英语、日语和韩语，确认购买页使用“内置的记忆表达方式”对应
   的四语文案，无 “first-party / 第一方 / ファーストパーティ / 자사”残留。
9. 从 Apple Photos 分享多张照片，验证 `Share → Processing → Notification →
   Apple Photos`，并分别覆盖静态照片、Live Photo、原始资源保护、EXIF/方向和
   保存回读。
10. 覆盖 Dynamic Type、VoiceOver、Family Sharing、订阅管理入口和 StoreKit
    暂时不可用时的恢复路径。
11. 在 macOS 上验证 Memory Subject 与 Preset 卡片横向等宽排列、真实预览持续可见、
    Card Content 与 Time & Place 的右侧 Inspector、文字编辑、智能内容插入、模块移除、
    保存后重载，以及窗口尺寸变化时的布局稳定性；确认这些平台交互没有改变 iOS
    共享数据流和持久化行为。

## 反馈信息

请附设备型号、系统版本、MemoMark 版本与构建号、权益类型（免费 / 历史永久 /
激活码永久 / 月度订阅 / 年度订阅 / TestFlight）、触发路径、是否涉及 Apple
Photos 写入，以及是否可以恢复。不要附带不必要的私人照片、姓名、地址或 Apple
账户信息。

## 状态边界

2.2.3、2.2.4 和此前 2.3.0 构建只作为验证历史；TestFlight Sandbox 的购买不能
证明正式版可用。正式版本、构建上传、审核和分发状态以 App Store Connect 的
独立证据为准。
