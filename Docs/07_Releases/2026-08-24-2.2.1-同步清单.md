# MemoMark 2.2.1 (90) 同步清单

## 1. 同步状态与决策门

- Primary loop：Engineering Loop（P1 媒体真实性与交接可靠性）和 Product Loop（P2 配置中心表达可理解性）保持为独立问题；本版本只汇总两条已完成的受控改进，不改变其所有权。
- 范围起点：已推送 `2.1.3 (86)`，基线提交 `a438e55`，2026-08-19。
- 范围终点：2026-08-24 当前本地工作树的可归属变更。
- marketing version：`2.2.1`；build number：`90`。
- 风险：P1（Apple Photos/Live Photo 保存、配对与交接）；P2（表达样式与 Configuration Center 可理解性）。原图保护、照片本地处理、Memory Engine、Layout Engine、Renderer 与 Share Extension 所有权均不改变。
- Apple-native 复用：Photos/PhotoKit 仍负责资源身份、Live Photo 配对与保存；MemoMark 只处理 intake、解析、渲染、交接与回读验证。
- 状态：`Version Locked; Device Install Authorized; Git Sync Pending; External Distribution Not Authorized`。
- Git 授权：本轮明确授权构建并安装到已识别的实体 iPhone 17 Pro Max；不能从真机安装授权推断 Git 暂存、提交或推送授权。
- 未授权：TestFlight 上传与 App Store 提交；两项外部交付仍需单独授权。

## 2. 工作树分类

### 正式同步范围（待验证和授权后暂存）

- Minimal/Classic White 表达样式、Presentation Artifact、Layout/Renderer 路由、配置持久化与预览一致性。
- Share Extension 到主 App 的 Live Photo provider handoff、真实身份恢复、still/video composition、PhotoKit readback、可恢复失败与不重复处理。
- 时间锚点年度生日语义、配置中心的表达/卡片样式语言收口、四语本地化和相关测试。
- `2.2.1 (90)` target 版本字段、应用内更新日志、CHANGELOG、README、CURRENT_STATUS、HANDOFF、发布目录索引和本整理包。

### 本地保留范围（不得暂存）

- DerivedData、`.xcresult`、签名或归档产物、设备容器、截图/录屏、私人照片及研究数据。
- `.autosync/`、`.codex/`、个人 Xcode 状态和未冻结研究实验资产。
- `2026-08-22-2.1.4-*` 四份本地 Draft：它们在 build 未锁定时形成，已被本 `2.2.1 (90)` 包取代，不属于本次建议暂存范围。

### 待决定范围

- Dynamic Type、长文本、各语言视觉复核、其他高成本媒体矩阵、StoreKit 和 App Store 外部证据的完成时机。
