# MemoMark 2.1.1 (77) 发布内容总表

## 版本与范围

- 版本：`2.1.1`
- 构建号：`77`
- 变更范围：记忆对象切换一致性修复与对应回归测试
- 定位：面向日常配置连续性的修复性体验更新
- 用途：应用内更新日志、App Store、TestFlight 与内部同步清单的统一事实来源

## 面向用户的完整更新说明

这次更新让记忆对象切换更加稳定、清楚。切换对象后，相关的时间锚点、记忆卡预览、Logo、输出设置和编辑内容会一起切换到对应的记忆上下文，减少页面之间显示不一致的情况。

### 记忆对象切换更连贯

- 切换记忆对象时，首页、记忆卡预览和编辑区域会同步显示目标对象的内容。
- 已保存的配置会保持为已保存状态；还没有保存配置的对象会明确作为当前对象的草稿继续编辑。
- 时间锚点、输出设置、Logo、记忆文字和四个内容区域会一起刷新。
- 增加了对象切换与预览更新的回归检查，降低切换后残留上一对象内容的可能性。

### 一直不变的原则

- 照片只在设备本地处理，不上传照片。
- 原始照片保持不变，时光记只保存新的结果。
- Apple Photos 仍然是照片的家，MemoMark 从系统分享流程开始工作。

感谢你的反馈。建议更新到 `2.1.1`，获得更连贯的记忆对象配置体验。

## 内部发布边界

- 本轮属于 V4 Product Loop 中的有界体验修复与 Engineering Loop 回归验证。
- 未改变 Memory Engine、Layout Engine、Renderer、Metadata、Export、PhotoKit 保存或配置持久化的所有权。
- 当前状态为 `Version Locked; Release Evidence Open`。
- Simulator 在本轮不可用；macOS 测试与部分真机启动/首页投影证据已记录，签名候选包、完整真机点按验收及 App Store Connect 外部证据仍需单独完成。
- `TX-001`、`BP-001` 与历史 `FAIL (Conditional)` 生产认证边界不因本版本而改变。
