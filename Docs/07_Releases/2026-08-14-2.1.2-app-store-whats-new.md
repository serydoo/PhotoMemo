# MemoMark 2.1.2 App Store 更新说明

## 简体中文

这次更新主要完善了配置中心在切换与恢复时的状态连续性。

- 切换记忆对象、配置或编辑页面时，卡片内容和输出设置更容易保持在当前记忆的上下文中。
- 重新进入配置中心后，预览、对象信息和配置选择保持一致。
- 异步加载的相册选项不会把过期结果带回当前页面。

照片仍然在设备本地处理，原始照片保持不变，时光记只保存新的结果。

## English (U.S.)

This update keeps Configuration Center state consistent when you switch and return.

- Card content and output settings stay with the memory you are working on when switching subjects, configurations, or editor pages.
- After reopening Configuration Center, the preview, subject details, and configuration choice stay aligned.
- Asynchronous album options no longer bring stale results into the current page.

Photos remain processed on device. Originals stay unchanged, and MemoMark saves a new result.
