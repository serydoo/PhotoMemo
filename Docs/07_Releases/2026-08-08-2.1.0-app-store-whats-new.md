# MemoMark 2.1.0 App Store 更新说明

## 简体中文

这次更新让配置、卡片编辑和照片分享更清楚、更自然。

- 卡片内容编辑明确对应最终照片中的四个位置，修改会实时同步预览。
- 右下内容可以写入照片说明，方便在 Apple Photos 中查找。
- 配置中心、记忆对象和设置页面减少重复层级，小屏阅读更轻松。
- Share 页面更清楚地展示分享内容与处理状态。
- 当前版本提供基础白边框，更多样式将在后续版本陆续开放。

照片仍然只在设备本地处理，原始照片保持不变，时光记只保存新的结果。

## English (U.S.)

This update makes configuration, card editing, and sharing clearer and more natural.

- Card content now clearly maps to the four positions in the final photo, with live preview updates.
- The bottom-right content can be written to the photo description for easier searching in Apple Photos.
- Configuration, memory-object, and settings pages use a clearer hierarchy, especially on smaller screens.
- Share now presents the shared content and processing state more clearly.
- The current release provides the Basic White border; more styles will arrive in later releases.

Photos are still processed only on your device. Originals remain unchanged, and MemoMark saves a new result.
