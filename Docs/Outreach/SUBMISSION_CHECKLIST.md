# 收录与媒体推荐提交清单

## A. 发送前事实核验

- [ ] App Store 页面可公开访问，链接在未登录状态下有效。
- [ ] 对外版本号使用 App Store 版本，不把 V4、V3 或内部构建号当作产品版本。
- [ ] 实际支持的 iPhone、iPad、Mac、Share Extension 和 Widget Extension 已确认。
- [ ] 价格、订阅、内购和 TestFlight 状态与页面一致。
- [ ] 官网、隐私政策、支持页面和联系邮箱可访问。
- [ ] “本地优先”“不上传照片”“不修改原图”等表述已由当前版本行为验证。
- [ ] 尚未完成的 Expression Style、生产认证、性能边界没有被写成已完成能力。
- [ ] 所有截图来自公开版本，不包含真实姓名、私有照片、地址、文件路径、设备标识或诊断信息。

## B. 媒体素材

- [ ] 1024×1024 产品图标。
- [ ] iPhone 竖屏截图 3–5 张。
- [ ] iPad 或 Mac 截图（如果该平台已公开支持）。
- [ ] Apple Photos → Share → MemoMark → Save 的完整流程截图或视频。
- [ ] 一张“原始照片 / 新记忆卡片”的说明图，明确原图没有被覆盖。
- [ ] 30–60 秒无声演示视频，首 3 秒说明产品是什么。
- [ ] 中英文产品简介各一份。
- [ ] 开发者简介 50–80 字。
- [ ] 公开版隐私说明和支持邮箱。

## C. Product Hunt

- [ ] Maker 账号资料完整。
- [ ] 产品名、Tagline、Description 已由 `CHANNEL_COPY.md` 派生。
- [ ] 发布日期避开无法持续回复评论的时间。
- [ ] 准备 3 个真实问题邀请早期用户反馈。
- [ ] 不购买投票、不组织机械互投、不复制粘贴骚扰消息。

## D. AlternativeTo

- [ ] 产品名称、平台和价格模型准确。
- [ ] 选择的是“照片日记 / 记忆呈现 / 个人时间线”相关关系，而非误导性的照片管理器。
- [ ] 替代品只填写用户确实可能进行比较的产品。
- [ ] 页面描述先讲用户结果，再讲本地处理和原图保护。
- [ ] 不请求虚假评分或批量制造评论。

## E. Indie Hackers

- [ ] 以产品过程、取舍和问题求反馈，不写成广告。
- [ ] 说明当前阶段和已验证范围。
- [ ] 准备回答本地处理、EXIF、Apple Photos 和用户反馈问题。
- [ ] 发布后 72 小时内至少回复一次有价值的评论。

## F. 少数派和 Apple 媒体

- [ ] 中文投稿有完整观点或实践，不只是功能列表。
- [ ] 每封媒体邮件只针对一个编辑或作者。
- [ ] 标题根据对方栏目改写，不群发同一标题。
- [ ] 提供体验版本和公开资料，不要求对方保证刊登。
- [ ] 5–7 个工作日无回复后最多跟进一次。

## G. 提交后记录

- [ ] 在 `OUTREACH_TRACKER.csv` 记录发送时间、链接、版本和负责人。
- [ ] 记录站点的页面 URL 和可见状态。
- [ ] 记录回复、拒绝原因、用户反馈和下一次动作。
- [ ] 发现产品事实变化时，停止使用旧文案并标记需要更新的渠道。
