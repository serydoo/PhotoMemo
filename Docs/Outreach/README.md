# MemoMark 收录与推荐资料包

本目录保存 MemoMark 面向 Product Hunt、软件目录、独立开发者社区、少数派和 Apple 媒体的统一外部资料。

当前发布草稿：[`2026-08-26-MemoMark-2.2.2-XHS.md`](2026-08-26-MemoMark-2.2.2-XHS.md)。

## 使用顺序

1. 先读 [`OUTREACH_MATERIALS_SPEC.md`](OUTREACH_MATERIALS_SPEC.md)，确认范围和事实边界。
2. 用 [`PRODUCT_POSITIONING.md`](PRODUCT_POSITIONING.md) 统一产品称呼、定位和核心卖点。
3. 从 [`PRESS_KIT_CONTENT.md`](PRESS_KIT_CONTENT.md) 准备公开素材。
4. 按站点使用 [`CHANNEL_COPY.md`](CHANNEL_COPY.md) 或 [`MEDIA_PITCHES.md`](MEDIA_PITCHES.md)。
5. 洽谈照片冲印合作时使用 [`PHOTO_PRINTING_PARTNER_KIT_2026-08-10.md`](PHOTO_PRINTING_PARTNER_KIT_2026-08-10.md)，并在发送前复核其中的价格、权益、联系方式与 Apple 合规边界。
6. 提交前逐项检查 [`SUBMISSION_CHECKLIST.md`](SUBMISSION_CHECKLIST.md)。
7. 每次提交后更新 [`OUTREACH_TRACKER.csv`](OUTREACH_TRACKER.csv)。

## 当前推荐顺序

`Product Hunt → AlternativeTo → Indie Hackers → 少数派 → MacStories → 9to5Mac / Macworld`

## 重要边界

- 资料包不会自动向第三方站点发帖、评论、投票或发邮件。
- 所有 `[PLACEHOLDER]` 必须在发送前替换并人工核验。
- V4 Expression Style 当前仍是研究和产品定义，不得写成已经发布的生产功能。
- 不上传私有照片、设备截图、诊断导出、内部路径或任何敏感信息。
- 照片冲印合作资料包含公开商务联系方式和时效性商业口径；公开或发送前必须由产品负责人再次确认。
