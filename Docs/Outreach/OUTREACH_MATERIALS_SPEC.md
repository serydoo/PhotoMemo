# MemoMark 收录与推荐资料包规格

## 目标

为 MemoMark（时光记）建立一套可复用、可审阅、可追踪的外部收录与编辑推荐资料。资料包服务于 Product Hunt、AlternativeTo、Indie Hackers、少数派以及 Apple 媒体定向 pitch，不代表这些站点已经接受收录，也不替代 App Store 审核或生产认证。

## 当前前提

- 当前产品阶段：`V4 Expression Style System / V4.0 Research And Product Definition`。
- V4 的 Expression Style 仍处于研究和产品定义阶段，资料不得声称该部分已经完成生产实现。
- MemoMark 仍是本地优先的 Memory Presentation Engine，不是照片管理器、云端照片产品或普通水印工具。
- 对外只宣传已可验证的能力；未验证的版本、下载状态、平台支持、媒体报道和用户数量使用占位符。
- 原图保护、本地处理、Apple Photos 工作流和隐私边界必须使用准确、可核验的表述。

## 交付物

1. `PRODUCT_POSITIONING.md`：统一中英文定位、短描述、核心卖点和禁止表述。
2. `CHANNEL_COPY.md`：各站点可直接粘贴的字段和正文。
3. `MEDIA_PITCHES.md`：MacStories、9to5Mac、Macworld 和中文媒体的定向邮件。
4. `SUBMISSION_CHECKLIST.md`：提交前的事实、素材、隐私和链接检查。
5. `OUTREACH_TRACKER.csv`：每个渠道的状态、负责人、链接、日期和后续动作。

## 成功标准

- 所有渠道文案都能从同一套定位派生，不出现产品名称、能力或平台承诺不一致。
- 每个主动提交渠道都有明确的提交类型、所需素材、下一步和风险提示。
- 所有外部文案都把“已验证事实”“可提供材料”“未来研究方向”分开。
- 不包含私有照片、个人联系方式、设备标识、内部路径、未公开诊断信息或秘密。
- 在正式发送前，仍需人工确认 App Store URL、版本号、平台支持、价格、隐私政策和实际可下载状态。

## 不在本资料包范围内

- 自动向第三方站点发帖、评论、投票或发送邮件。
- 购买排名、购买投票、批量 SEO 目录提交或伪造用户评价。
- 改变 MemoMark 的 Swift 架构、Renderer、Export、PhotoKit 或持久化行为。
- 将 V4 研究方向包装成已经发布的功能。
