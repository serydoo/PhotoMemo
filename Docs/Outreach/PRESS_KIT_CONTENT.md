# MemoMark Press Kit 内容稿

## Short bio

MemoMark（时光记）是一款本地优先的 Apple 记忆呈现 App。它从 Apple Photos 中的真实照片和拍摄时间出发，让用户围绕重要的人、时间起点和自己的文字制作一张新的记忆卡片，同时保留原始照片。

## English short bio

MemoMark is a local-first Apple memory presentation app. It starts with a real photo and its capture time, lets people shape a memory around a person, a time anchor, and their own words, and creates a new card while keeping the original photo intact.

## Developer note

MemoMark is being refined as a local-first Memory Presentation Engine. The project trusts Apple Photos to manage the photo library and focuses on the smaller question of how a photo can retain the context of a person's life without surrendering the original asset or private data to a cloud service.
