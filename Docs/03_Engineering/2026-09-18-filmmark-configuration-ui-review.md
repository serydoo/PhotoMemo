## 观察到的现象

- `卡片内容`、`位置`、`底色衬托` 使用了不同的标题/副标题内容列，右侧值、按钮和箭头的轨道不稳定。
- 位置微调的复位按钮独占下一行，使用刷新样式图标，与四向微调控制的关系不紧凑。
- 字号、颜色和底色都在较长的主页面中展开，字体与时间地点也没有清晰的低频设置边界。
- 时间与地点原本嵌入主页面，复用了另一套内容列，导致左右过度贴边。
- 卡片内容编辑继续使用独立编辑覆盖层；本记录只处理 FM 配置页的样式设置，不改变内容编辑器的输入和模块语义。

## 本轮目标

主页面保留一个真实 FM 顶部预览，并围绕它提供一条短而可扫描的高频路径：

```text
卡片内容 → 位置 → 字号 → 颜色 → 底色衬托 → 胶片样式与细节
```

其中“胶片样式与细节”是无预览的二级页，承载字体和时间与地点；原生 sheet 可以遮挡主页面，但不复制主预览。预设与自定义颜色统一放在主页面。所有控件继续写入同一个 `FilmMarkConfiguration` draft，不新增 UI 数据源，也不改变 Preview → Layout → Renderer → Export 链路。

## 实现边界

- 统一 FM 一级导航行的 trailing 内容列，保持标题、说明和值/箭头的同一水平轨道。
- 位置微调改为左侧说明与复位、右侧四向按钮的紧凑布局；复位为 88pt 宽、28pt 可见高度，保留与方向按钮相同的至少 44pt 点击高度，不再使用刷新图标。
- 字号、颜色预设和底色使用一致的 FM 标题/副标题样式；底色四项在普通宽度四列均分，辅助字号降为 2×2。
- 二级页只承载低频设置和时间/地点行，不放任何 `FilmMarkPreviewSurface`。
- 保留 macOS 的 `filmMarkDetails` Inspector 路由；iOS 仅增加本地详情 sheet，不改变跨平台配置模型。
