Use the safe live root viewport, system traits and Dynamic Type. No model-name,
idiom, global screen or orientation-device branching. Current regular width AND
regular height required; minimum safe viewport700pt wide and640pt tall. These
are V5.2 content-capacity bounds, not hardware claims:350pt minimum readable
region plus existing16pt inner margins; vertical two-region capacity280pt each
plus switcher/spacing budget. Minimum region width scales with body text.

Horizontal requires width > height and two readable350pt/scaled columns with
existing margins plus12pt gutter. Otherwise an eligible window stacks regions.
Accessibility text sizes fall back to current navigation/content, avoiding tiny
split regions. Invalid/nonfinite/unknown/insufficient inputs fall back. Thus phone
portrait and ordinary compact-height landscape remain exactly the current path.
Narrow iPad windows retain the existing V5.1 navigation decision and content.
