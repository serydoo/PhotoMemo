# GlassCard 完整功能联调包

2026-09-30，main 当前工作区，未提交或推送。App 版本仍为 2.3.4（115）；这是当前源码构建的完整 Debug 包，未进行 App Store 发布。

## 已接通

- 第四样式 `glassCard`，Debug 配置中心显示“玻璃卡片”；Release 暂不提供新增样式选择入口。
- 四个位置复用现有 TemplateItems、模块插入与字段编辑。GlassCard 保存独立模板，不替换 Classic White、Minimal 或 FilmMark 的内容。
- 四区域、徽标与分隔线由 Layout 定位，字号适配产生 resolved plan；配置预览和正式 artifact 共用绘制层。
- 同一固定深色透明层联调基线用于所有素材，不按场景挑选配方。当前黑色 0.42 透明度、精确字号及边框仍可在后续研究中调整。
- 通过现有 RecordCardExportPipeline 接入静态文件与照片保存、EXIF/描述、输出相册和恢复机制。
- Live Photo 入口使用同一 artifact，沿用现有几何解析、视频合成、配对身份、PhotoKit 保存与回读服务。
- GlassCard 配置与生产快照、Share 冻结快照接通；修复了旧冻结逻辑仅接受 FilmMark 而丢失 GlassCard 样式的问题。
- 空内容及已知溢出停止输出；配置预览有提示，批处理溢出提供中英日韩恢复文案。

## 验证结果

- 最终全量 macOS 测试：1947 通过，1 跳过，0 失败。
- 横竖 JPEG 文件导出/读回：尺寸正确、原文件未改动、玻璃栏在底部；Live Photo artifact 和 canonical geometry 校验通过。
- iOS Simulator Debug 构建（含 Share Extension）：通过；统一配置预览的横竖 GlassCard 截图和 AX 已保存。
- iPhone 17 Pro Max / iOS 27.2：完整 Debug 签名构建通过，codesign 严格核验通过，覆盖安装成功，无卸载或清空数据。首次 CLI 启动被锁屏拒绝；此为当时的工具记录。用户随后于本轮反馈“功能没问题”，确认初步功能测试通过。
- Release Simulator 构建通过；研究页符号未发现，正式 GlassCard renderer 代码存在，新样式选择入口仍按 DEBUG 条件限制。

测试与几何接口证据不代替真机 Live Photo 视频合成、Photos 保存/回读或肉眼验收。之前独立 Core Image 普通 MOV 实验没有用于替换生产输出路径。

## 现在怎么检查

1. 打开 MemoMark，进入配置中心。建议新建测试预设，在卡片样式里选择“玻璃卡片”，并保存。
2. 设置四区域短文，切换横竖预览；检查字体、上下对齐、徽标位置与自定义头像。长文应出现明确提示，不应悄悄保存不完整内容。
3. 将该预设设为处理默认，在 Photos 分享普通照片给 MemoMark，检查新照片保存、信息栏位置、EXIF、相册和原片保护。
4. 使用竖向 IMG_7027、横向 IMG_7033 Live Photo，选保留动态，检查回到 Photos 后可播放、关键帧与边框一致、音轨和方向正常。
5. 切回原有 Minimal，核对保存和 Live Photo 没有回归。无障碍继续按此前约定统一验收。
