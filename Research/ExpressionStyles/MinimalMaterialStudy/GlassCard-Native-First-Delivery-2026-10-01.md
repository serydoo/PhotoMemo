## Production integration boundary

Native material rasterization is feasible; custom shader/container work is no longer justified by an assumed native-export omission. Next bounded production slice must carry source-dependent material through the existing renderer-neutral PresentationArtifact contract, retaining Layout ownership and foreground text layers. Still composition and motion-frame composition must consume the same material description. Existing fixed CALayer overlays cannot sample the changing video background, so adding glassEffect to the preview alone or baking the still's material into a static overlay is rejected.

Evaluate AVFoundation's source-frame composition handler before introducing a custom compositor or replacing AVAssetExportSession. Preserve current canonical transform, audio, pairing-identity/timed-metadata preparation, metadata writer and Photos transaction. SwiftUI native raster work has MainActor ownership; synchronous still composition interfaces require an explicit asynchronous adapter rather than blocking the main actor or changing all existing renderer paths. Older systems retain the accepted fixed-alpha implementation through an explicit capability fallback. Close orientation/crop and cancellation/failed-export checks plus existing renderer regression tests before scoped commit. Production native default and final main integration are not yet complete; do not treat this DEBUG study as their completion.
