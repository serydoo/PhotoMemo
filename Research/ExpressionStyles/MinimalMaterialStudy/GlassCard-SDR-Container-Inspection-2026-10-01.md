# Controlled container inspection

Engineering Loop P1 research only. Build read-only PNG chunk/CRC and HEIC meta/iinf/iloc inspector, then bounded TIFF EXIF UserComment reader. Reject truncated, external, fragmented or unsupported metadata references rather than guessing. No container writes or production dependencies. Native writer generates controlled fixtures; attach output bytes and ImageIO properties. Compare raw payload with returned string to distinguish stored encoding from decoding. PNG W3C third-edition eXIf/chunk CRC and libheif implementation are reference evidence. Valid fixture inspection does not certify arbitrary user containers.

## Evidence and outcome

References: W3C PNG third edition https://www.w3.org/TR/png-3/ (eXIf/chunk structure/CRC); libheif primary container implementation https://github.com/strukturag/libheif/blob/master/libheif/box.cc (infe/iloc field layout). Read-only inspector is original Python, limited to classic TIFF, one eXIf chunk, one unprotected Exif item, iloc versions0–2/method0/data-reference0/single extent within mdat. Unsupported paths reject; no container editing.
