# Swift PNG repair research kernel

Engineering Loop P1 research. Scope PNG only, Foundation value kernel with Sendable input/output, no filesystem/production dependencies. Reuse native ImageIO only in readback tests. Inspect all reachable classic TIFF IFD tables and external value ranges before patch: reject overlapping ranges, duplicate/cyclic references, unsupported private MakerNote/SubIFD/thumbnail conventions. Hard research limits: 16MiB file, 1024 chunks/tags, 32 IFDs. Maintain existing data size; only UserComment storage/count/eXIf CRC changes. Validate against Python controlled outputs plus little/big endian and adversarial overlap/cycle/bounds/capacity cases. No general PNG/HEIC validator or production certification.
