# Research History

## 2026-09-26

Started a unified visual review of recent Home preset-row, Configuration Center
preview, Classic White portrait, and FilmMark overflow changes. The review
reuses existing design tokens and frozen Configuration Center structure. It
records the current edge-button interaction contract, two source-verified
preview/output fidelity gaps, and the physical-device acceptance still open
for the combined recent UI state. The first bounded correction slice removed
the FilmMark full-photo-only shade, aligned Classic White measurement with its
system font weights, and added the visible logo-mark name to the Home row's
four-language VoiceOver label. See
`VisualPrototypes/MemoMark-Cross-Surface-Visual-Review-2026-09-26.md`.

## 2026-09-24

The owner approved promoting the preview direction from a local review route
into the existing iOS Configuration Center preview. The bounded product slice
uses the owner-provided shared Mid-Autumn landscape/portrait pair across
Classic White, Minimal, and FilmMark; orientation and fit/full-canvas viewing
state are local interface preferences only. Output configuration, preset
content, renderer/layout behavior, and the separate macOS/top-summary previews
remain unchanged. Implementation and Baguette evidence are recorded in
`VisualPrototypes/ConfigurationPreviewProductionIntegration-2026-09-24.md`.

## 2026-09-23

Added the first external design study of recent Apple-featured and Apple Design
Award apps. The study records source type and evidence limits, extracts
interface, interaction, visual, accessibility, and localization observations,
and maps them to bounded MemoMark V4 research hypotheses. It does not authorize
new production behavior or implementation.

## 2026-07-30

MemoMark formally started `V4 Expression Style System`, subphase
`V4.0 Research And Product Definition`. The former Expression Style research
seed is now the active V4 research foundation.

This transition authorizes `ES-001 User Expression Scenarios`, taxonomy,
synthetic studies, measurable specifications, and Product Design Review
preparation. It does not freeze the product model or authorize production
implementation. `TX-001`, `BP-001`, and a superseding production reliability
certification remain the parallel V4 Entry Engineering Gate.

## 2026-07-20

MemoMark archived the initial Expression Style System thesis as a possible V4
research direction. The seed separates user-owned Presets, semantic
MemoryBehavior, visual Expression Style, and bounded Style Variants so future
style growth does not become an unstructured template catalog.

The archive records Classic, Minimal, Signature, Film, and Magazine as visual
research candidates, while Baby, Travel, Journal, and Story remain behavior
candidates. A horizontal real-preview Style Library is preserved as an
interaction hypothesis inside the existing Configuration Center boundary.

This work changed documentation only. It did not start V4, freeze a PDR, or
authorize implementation. MemoMark remains in V3 Production Quality And
Delivery, with TX-001, BP-001, and reliability certification closure ahead of
any Expression Style source work.

## 2026-06-22

MemoMark entered V2 Research Phase.

Development, UI polishing, and renderer polishing were paused so the project can become a local-first Photo Presentation Engine with research, specification, and Layout Engine as first-class assets.

The Project Constitution was added as the highest-level repository rule. It clarified that old documentation should not be migrated immediately; new research documentation must be built first, and migration should wait until research specifications stabilize.
